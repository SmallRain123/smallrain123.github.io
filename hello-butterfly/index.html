你好，Butterfly：搭一个可持续输出的技术博客

发表于2026-10-29|更新于2026-10-29|建站

一直想有一个不依赖平台的地方，存放那些散落在笔记软件、聊天记录和脑子里的技术经验。于是有了这个站点：小鱼技术栈。

它不追热点，也不追求日更，只希望每解决一个问题，就留下一条以后还能找到的路。

为什么是 Hexo + Butterfly

Hexo 的定位很纯粹：Markdown 写文章，一条命令生成静态页面，没有数据库，也没有需要长期维护的后台。对个人博客来说，这种简单本身就是一种可靠性。

Butterfly 则补齐了阅读体验：文章卡片、目录、搜索、归档、标签、暗色模式，基本开箱即用。它允许你只改配置就得到一个完整的站点，也留了足够的 CSS 和模板空间做自己的风格。

工具应该降低表达的摩擦，而不是成为表达本身。

已经打开的能力

  • 本地全文搜索：不依赖第三方搜索服务，构建时生成索引。
  • 亮 / 暗色模式：默认深海蓝暗色主题，也可以切回亮色。
  • 文章目录与相关推荐：长文阅读时快速定位。
  • 归档、分类、标签：按时间或主题重新组织内容。
  • RSS 与 sitemap：/atom.xml 和 /sitemap.xml 开箱可用。
  • 自定义 404：静态站点也可以有完整的错误页。
