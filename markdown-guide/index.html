Markdown 写作速查：让排版回归简单

发表于2026-10-26|更新于2026-10-26|写作

Markdown 的好处，是让写作重新变成“写”本身。不用在工具栏里寻找按钮，几个符号就能把结构交代清楚。这篇当作自己的速查表，也分享给同样在写字的人。

最常用的几种语法

标题与强调

正文里少用一级标题，把 ## 留给文章的章节，阅读节奏会更稳定。

列表与引用

链接与图片

图片描述不要省略。它既是给搜索引擎的说明，也是图片加载失败时读者能看到的最后一点信息。

写长文的三个小习惯

  1. 一段只说一件事。 中文段落超过五六行，读者就会开始跳读。
  2. 用小标题切分节奏。 小标题不是目录装饰，而是给读者的一次喘息。
  3. 代码块标注语言。 高亮和复制按钮都依赖它，别让读者猜。

一个简单的表格

语法 用途 使用频率
## 章节标题 高
> 引用 中
``` 代码块 高
--- 分隔线 低

最后

工具越简单，越容易坚持。Markdown 不完美，但它足够快，足够安静，也足够把注意力还给内容本身。
