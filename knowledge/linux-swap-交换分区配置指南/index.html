Linux Swap 交换分区配置指南

← 返回知识库

Linux / 系统#知识库#Linux / 系统#Linux

Swap（交换分区）是磁盘上的一块区域，当物理内存（RAM）耗尽时，操作系统会将部分不活跃的内存页移动到 Swap 空间，从而释放物理内存供当前运行的进程使用。Swap 不是内存的替代品，而是作为内存不足时的安全缓冲。

现代 Linux 系统内存通常较大，Swap 仍建议配置，主要用于：内存峰值突发时的缓冲、休眠功能（hibernation）支持、以及 OOM 发生前的最后防线。

查看当前 Swap 状态

在开始配置前，先检查系统是否已有 Swap 空间：

# 查看所有 Swap 设备及其大小
swapon --show

# 或使用 free 命令查看内存与 Swap 总量
free -h

# 查看详细的 Swap 使用情况
cat /proc/swaps

如果输出为空或全为 0，表示系统当前未配置 Swap。

方式一：创建 Swap 文件（推荐）

Swap 文件是最灵活的方式，无需重新分区，可随时调整大小，适用于云服务器、VPS 和大多数现代 Linux 发行版。

1. 创建 Swap 文件

以下示例创建一个 2GB 的 Swap 文件，可根据需要调整大小：

# 创建 /swapfile 文件，大小为 2G
dd if=/dev/zero of=/swapfile bs=1G count=2

# 或使用 fallocate（更快，支持的文件系统上推荐）
fallocate -l 2G /swapfile
注意：某些文件系统（如 XFS 的某些版本）不支持 fallocate 创建 Swap 文件，此时应使用 dd 命令。如果 mkswap 报错，请改用 dd 方式重新创建。

2. 设置正确的权限

Swap 文件必须只有 root 可读写，否则系统会拒绝启用：

chmod 600 /swapfile

3. 格式化为 Swap 区域

mkswap /swapfile

4. 启用 Swap 文件

swapon /swapfile

# 验证是否生效
swapon --show

5. 配置开机自动挂载

将 Swap 文件写入 /etc/fstab，确保重启后自动启用：

# 追加到 /etc/fstab 末尾
echo '/swapfile none swap defaults 0 0' >> /etc/fstab

# 验证 fstab 配置是否正确（不实际挂载）
mount -a

方式二：创建 Swap 分区

如果有未使用的磁盘分区，可以直接将其设置为 Swap 分区。这种方式性能略优于 Swap 文件，但灵活性较差。

1. 查看磁盘分区

# 列出所有块设备
lsblk

# 或使用 fdisk 查看
fdisk -l

2. 创建分区（如需要）

使用 fdisk 或 parted 在磁盘上新建一个分区作为 Swap：

# 进入磁盘（以 /dev/sdb 为例）
fdisk /dev/sdb

# 在 fdisk 交互界面中：
# n        — 新建分区
# p        — 主分区
# 回车     — 使用默认扇区起始位置
# 回车     — 使用默认扇区结束位置（或指定 +2G 表示 2GB）
# t        — 修改分区类型
# 82       — 设置为 Linux swap 类型
# w        — 保存并退出

3. 格式化为 Swap

# 假设分区为 /dev/sdb1
mkswap /dev/sdb1

4. 启用并设置开机挂载

# 启用
swapon /dev/sdb1

# 写入 fstab 实现开机自动挂载
echo '/dev/sdb1 none swap defaults 0 0' >> /etc/fstab

Swap 大小建议

Swap 大小并非越大越好，需根据物理内存大小和使用场景决定：

物理内存大小 无休眠需求时 Swap 大小 需要休眠（Hibernate）时 Swap 大小
2GB 及以下 等于内存大小 2 倍内存大小
2GB ~ 8GB 等于内存大小 等于内存大小
8GB ~ 64GB 4GB ~ 8GB 内存大小的 1.5 倍
64GB 以上 4GB ~ 8GB（固定） 根据需要调整
服务器场景：通常配置 2GB \~ 8GB Swap 即可，主要用于 OOM 缓冲。数据库服务器建议适当增大。桌面笔记本如需休眠功能，Swap 至少等于物理内存大小。

Swappiness 参数调优

vm.swappiness 参数控制系统使用 Swap 的积极程度，值范围 0 ~ 100，默认值通常为 60。值越小，系统越倾向于使用物理内存，越少使用 Swap。

查看当前 swappiness 值

cat /proc/sys/vm/swappiness

临时修改（立即生效，重启失效）

# 服务器推荐设为 10（减少 Swap 使用）
sysctl vm.swappiness=10

# 桌面系统可设为 1（尽量不用 Swap）
sysctl vm.swappiness=1

永久修改

# 写入 sysctl 配置文件
echo 'vm.swappiness = 10' >> /etc/sysctl.conf

# 使配置生效
sysctl -p
场景 推荐 swappiness 值 说明
生产服务器（数据库、应用） 1 ~ 10 尽量使用物理内存，避免 Swap 影响性能
桌面/笔记本 10 ~ 60 根据内存大小调整，内存大可设低一些
内存紧张的旧机器 60（默认） 保留默认值，让系统更积极地使用 Swap

禁用与删除 Swap

临时禁用 Swap

swapoff -a

# 或关闭指定 Swap
swapoff /swapfile

永久删除 Swap 文件

# 1. 关闭 Swap
swapoff /swapfile

# 2. 从 /etc/fstab 中删除对应行
sed -i '/\/swapfile/d' /etc/fstab

# 3. 删除 Swap 文件
rm /swapfile

删除 Swap 分区

# 1. 关闭 Swap
swapoff /dev/sdb1

# 2. 从 /etc/fstab 中删除对应行
sed -i '/\/dev\/sdb1/d' /etc/fstab

# 3. 如需重新使用该分区，用 fdisk 删除并重建分区
fdisk /dev/sdb

验证与排查

验证 Swap 是否正常工作

# 查看 Swap 设备列表
swapon --show

# 查看内存和 Swap 总体使用情况
free -h

# 查看 Swap 的详细使用统计
vmstat 1 5

常见问题

问题1：swapon 提示 “Permission denied”

原因：Swap 文件权限不正确。解决：执行 chmod 600 /swapfile 确保只有 root 可读写。

问题2：mkswap 提示 “is more than half of memory”

原因：Swap 文件过大。解决：Swap 大小无需超过物理内存太多，按前文建议调整即可。

问题3：重启后 Swap 未自动启用

原因：/etc/fstab 配置有误。解决：执行 mount -a 检查报错，确认 fstab 中 Swap 行格式正确。

问题4：系统卡顿，Swap 使用很高

原因：物理内存不足，系统频繁在内存和 Swap 之间交换数据（thrashing）。解决：增加物理内存，或调整 swappiness 参数，优化应用内存占用。
