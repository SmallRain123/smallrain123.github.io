Claude code小白教程

← 返回知识库

AI / 工具#知识库#AI / 工具#Claude
  • Nodejs （建议使用nvm工具安装node和npm，链接是https://github.com/coreybutler/nvm-windows/releases）
  • Git
  • Longcat

一、Claude code安装

1.1 安装nodejs

# 安装nodejs 24版本
nvm install 24
# 切换版本
nvm use 24

#验证版本
node -v 
npm -v

1.2 安装claude code

npm i -g @anthropic-ai/claude-code

注意：需要在`C:\users\用户`目录下安装

二、Claude code配置

2.1 .claude.json文件增加一下内容

  "hasCompletedOnboarding": true
  "showSpinnerTree": false

2.2 配置settings.json文件

{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "sk-******************************",
    "ANTHROPIC_BASE_URL": "https://api.deepseek.com/anthropic",
    "API_TIMEOUT_MS": "30000",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": 1,
    "CLAUDE_MODEL": "deepseek-v4-pro"
  }
}

2.3 更新

  • 直接输入claude install更新到最新版本即可

2.4 测试

  • 直接使用大模型启动，因为我使用的longcat，是免费的版本，这个是链接https://longcat.chat
claude --model LongCat-Flash-Chat
  • 输入claude install 更新下

注意: api地址和token不是免费的，需要收费
