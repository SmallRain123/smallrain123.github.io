vs code 插件备份与导出

← 返回知识库

开发环境#知识库#开发环境

这是最常用的方式，可快速备份所有插件 ID 并在新环境批量安装。

  1. 准备工作

    • 确保 VS Code 的code命令已加入系统 PATH（Windows 安装时勾选 “Add to PATH”，macOS/Linux 可通过 “Command Palette→Install ‘code’ command in PATH” 配置）。

  2. 导出步骤

    1. 打开 VS Code 集成终端（Ctrl+`）或系统终端。
    2. 执行命令导出所有插件 ID 到文本文件：
    code --list-extensions > extensions.txt
    • 导出仅启用的插件（Linux/macOS）：
    code --list-extensions --show-versions | grep -v "^\[disabled\]" | cut -d' ' -f1 > extensions.txt
    • Windows PowerShell 导出（避免编码问题）：
    code --list-extensions | ForEach-Object { $_.Trim() } | Out-File -Encoding UTF8 extensions.txt

  3. 批量安装（新环境）

    • Linux/macOS：
    cat extensions.txt | xargs -n 1 code --install-extension
    • Windows PowerShell：
    Get-Content extensions.txt | ForEach-Object { code --install-extension $_ }

二、导出单个插件为 VSIX 安装包（离线分发）

适合导出特定插件用于离线安装，支持单个导出或通过命令行批量打包。

  1. 图形化导出（单插件）

    1. 打开扩展面板（Ctrl+Shift+X），找到目标插件。
    2. 点击插件右侧的 “…”，选择 “在 Marketplace 中显示”，进入插件页面。
    3. 下载对应版本的 VSIX 文件（部分插件可能不提供直接下载），或在插件页面中找 “Download Extension” 选项。

  2. 命令行导出（需安装 vsce 工具）

    1. 安装 vsce（Node.js 环境）：
    npm install -g vsce
    1. 导出指定插件为 VSIX：
    vsce package --baseContentUrl https://marketplace.visualstudio.com/items?itemName=插件ID --baseImagesUrl https://marketplace.visualstudio.com/items?itemName=插件ID
    1. 示例（导出 Python 插件）：
    vsce package --baseContentUrl https://marketplace.visualstudio.com/items?itemName=ms-python.python --baseImagesUrl https://marketplace.visualstudio.com/items?itemName=ms-python.python

  3. 手动获取插件文件（应急方案）

    1. 找到插件安装目录：

      • Windows：%USERPROFILE%\.vscode\extensions
      • Linux：~/.vscode/extensions
      • macOS：~/Library/Application Support/Code/extensions

    2. 复制对应插件文件夹，压缩后即可用于离线安装（安装时选择 “从 VSIX 安装”）。

三、第三方插件辅助导出（简化操作）

安装VSC Export & Import插件（aslamanver.vsc-export），通过命令面板快速导出 / 导入插件列表：

  1. 安装插件后，按 Ctrl+Shift+P，输入 “VSC Export” 生成vsc-extensions.txt。
  2. 导入时输入 “VSC Import”，选择文件即可批量安装。

四、常见问题与注意事项

  1. code命令未找到：重新安装 VS Code 并勾选 “Add to PATH”，或通过命令面板配置 PATH。
  2. 导出失败：检查插件是否为内置插件（无法导出），或网络连接是否正常。
  3. 版本兼容性：导出的 VSIX 文件需与目标 VS Code 版本兼容，建议使用最新版本。
