Windows 11 安装 uv包括：更新、常用命令、Python 管理、环境切换等,（Astral 的 Python 包/环境工具）完整指南

← 返回知识库

开发环境#知识库#开发环境

下面给你一套 Windows 11 已安装 uv（Astral 的 Python 包/环境工具）完整指南，包括：更新、常用命令、Python 管理、环境切换等，直接照着用就行。

一、UV 更新方法

uv 是一个单文件工具，更新非常简单：

✅ 方法1（推荐）

uv self update

✅ 方法2（重新安装覆盖）

如果上面失败，可以直接重新安装（会自动覆盖旧版本）：

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

✅ 检查版本

uv --version

以上安装部上可以试试这个方案：

通过winget安装

winget install --id=astral-sh.uv -e

二、UV 核心概念（你必须知道）

uv ≈ pip + virtualenv + pyenv + poetry 的结合体：

功能 uv 对应
安装 Python uv python install
管理版本 uv python list
创建虚拟环境 uv venv
安装依赖 uv pip install
运行脚本 uv run

三、Python 版本管理（重点）

1️⃣ 查看可安装 Python 版本

uv python list

👉 会显示：

2️⃣ 安装 Python（推荐 3.11 或 3.12）

uv python install 3.11

或指定版本：

uv python install 3.11.9

3️⃣ 查看已安装 Python

uv python list --installed

4️⃣ 设置全局默认 Python

uv python pin 3.11

👉 类似 pyenv global

5️⃣ 项目级 Python（推荐）

进入项目目录：

uv python pin 3.11

会生成：

.python-version

6️⃣ 使用指定 Python 运行

uv run --python 3.11 python script.py

四、虚拟环境（替代 venv / conda）

1️⃣ 创建虚拟环境

uv venv

或指定 Python：

uv venv --python 3.11

2️⃣ 激活环境（Windows）

.venv\Scripts\activate

3️⃣ 删除环境

直接删 .venv 文件夹即可

五、依赖管理（替代 pip）

1️⃣ 安装包

uv pip install open-webui

2️⃣ 安装 requirements.txt

uv pip install -r requirements.txt

3️⃣ 导出依赖

uv pip freeze > requirements.txt

4️⃣ 升级包

uv pip install -U 包名

六、运行项目（很强大）

1️⃣ 直接运行 Python

uv run python main.py

2️⃣ 自动创建环境 + 安装依赖（神器）

如果有 pyproject.toml：

uv run main.py

👉 uv 会自动：

七、项目初始化（类似 poetry）

uv init

生成：

八、锁定依赖（比 pip 更强）

uv lock

生成：

uv.lock

九、常见实战命令（你这种场景）

👉 安装 Python 3.11 + 创建环境

uv python install 3.11
uv venv --python 3.11

👉 安装 open-webui（你之前场景）

uv pip install open-webui

👉 运行 open-webui

uv run open-webui serve

👉 使用代理（国内）

set HTTP_PROXY=http://127.0.0.1:7890
set HTTPS_PROXY=http://127.0.0.1:7890

十、UV vs pip / conda（重点理解）

功能 uv pip conda
速度 🚀 极快 慢 中
Python管理 ✅ ❌ ✅
虚拟环境 ✅ ❌ ✅
锁文件 ✅ ❌ ✅
自动环境 ✅ ❌ ❌

👉 结论：

uv = 下一代 Python 工具（强烈建议你全面替换 pip + venv）
