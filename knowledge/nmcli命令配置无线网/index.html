nmcli命令配置无线网

← 返回知识库

Linux / 系统#知识库#Linux / 系统#Linux

一、打开终端。

二、查看网络设备状态：

首先，确认你的WiFi硬件是否被识别且开启。

nmcli radio wifi

如果输出是 disabled，请先启用它：

nmcli radio wifi on

三、扫描可用的 WiFi 网络：

nmcli device wifi list

或者使用 rescan 命令强制刷新列表：

nmcli device wifi rescan
nmcli device wifi list

这将显示一个列表，包括每个网络的 SSID（名称）、信号强度、安全类型等。

四、连接到一个 WiFi 网络：

使用以下命令进行连接，系统会提示你输入密码：

nmcli device wifi connect <SSID名称> password <你的密码>

请将 <SSID名称> 替换为你的 WiFi 名称，将 <你的密码> 替换为你的 WiFi 密码。

示例：
要连接一个名为 MyHomeWiFi，密码为 secret123 的网络：

nmcli device wifi connect MyHomeWiFi password secret123

五、验证连接：

连接成功后，你会看到类似 Device 'wlan0' successfully activated with ... 的消息。
你可以使用以下命令查看连接状态和获取的 IP 地址：

nmcli connection show
# 或者ip addr show
# 或者测试连通性ping -c 4 google.com

六、连接吉利或极氪无线网络

吉利：

sudo nmcli connection add \
    type wifi \
    con-name "Geely-Group" \
    ifname wlan0 \
    ssid "Geely-Group" \
    wifi-sec.key-mgmt wpa-eap \
    802-1x.eap peap \
    802-1x.phase2-auth mschapv2 \
    802-1x.identity "geely.auto\\e-xiaoyu.zhang3" \
    802-1x.password "Zhang19980213" \
    802-1x.anonymous-identity "anonymous" \ # 某些网络需要匿名身份
    802-1x.ca-cert "" \ # 显式设置为空，不验证CA
    802-1x.domain-suffix-match "" # 显式设置为空，不验证域名

极氪:

sudo nmcli connection add \
    type wifi \
    con-name "ZEEKR-Working" \
    ifname wlan0 \
    ssid "ZEEKR-Working" \
    wifi-sec.key-mgmt wpa-eap \
    802-1x.eap peap \
    802-1x.phase2-auth mschapv2 \
    802-1x.identity "geely.auto\\e-xiaoyu.zhang3" \
    802-1x.password "Zhang19980213" \
    802-1x.anonymous-identity "anonymous" \ # 某些网络需要匿名身份
    802-1x.ca-cert "" \ # 显式设置为空，不验证CA
    802-1x.domain-suffix-match "" # 显式设置为空，不验证域名

激活网卡：

nmcli connection up "Geely-Greoup" # 使用上面设置的con-name

查看配置：

nmcli connection show # 查看所有保存的连接设置
nmcli connection show "Geely-Group" # 查看配置的详细设置（用于检查配置）
