NVIDIA 显卡驱动 + Docker GPU 环境完整教程

← 返回知识库

GPU / 驱动#知识库#GPU / 驱动#Docker#NVIDIA
  • 系统：Ubuntu/Debian 系列（本文以 Ubuntu 24.04 为例）
  • 显卡：NVIDIA RTX A4000（其他 NVIDIA 显卡通用）
  • 目标：宿主机安装显卡驱动 → 安装 Docker → 配置容器调用 GPU

二、宿主机安装 NVIDIA 显卡驱动

2.1 前置检查

# 查看显卡型号
lspci | grep -i nvidia
# 查看系统版本uname -m && cat /etc/*release

2.2 禁用开源 nouveau 驱动（必须）

sudo bash -c "echo blacklist nouveau > /etc/modprobe.d/blacklist-nouveau.conf"sudo bash -c "echo options nouveau modeset=0 >> /etc/modprobe.d/blacklist-nouveau.conf"sudo update-initramfs -usudo reboot

重启后验证（无输出即为成功）：

lsmod | grep nouveau

2.3 安装官方驱动（推荐 apt 方式）

sudo apt update
sudo apt install -y nvidia-driver-570  # 适配 CUDA 13.1，稳定版本sudo reboot

2.4 验证驱动

执行以下命令，输出 GPU 信息即为成功：

nvidia-smi

三、安装 Docker 引擎

3.1 卸载旧版本

sudo apt remove -y docker docker-engine docker.io containerd runc

3.2 安装依赖并配置官方源

sudo apt update
sudo apt install -y ca-certificates curl gnupg lsb-release

# 添加 GPG 密钥
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg

# 添加 Docker 软件源
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

3.3 安装 Docker

sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io

# 免 sudo 使用 docker
sudo usermod -aG docker $USER
newgrp docker
# 验证安装
docker run hello-world

四、配置 Docker 支持 NVIDIA GPU（核心步骤）

4.1 安装 NVIDIA Container Toolkit

# 添加 NVIDIA 源
curl -fsSL https://nvidia.github.io/nvidia-docker/gpgkey | sudo gpg --dearmor -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg

distribution=$(. /etc/os-release;echo $ID$VERSION_ID)curl -s -L https://nvidia.github.io/nvidia-docker/$distribution/nvidia-docker.list | sudo tee /etc/apt/sources.list.d/nvidia-docker.list

# 安装工具包
sudo apt update
sudo apt install -y nvidia-container-toolkit

如果安装的过程中提示安装报错，可以查看常见问题排查

4.2 配置 Docker 并重启

# 自动配置 Docker 运行
sudo nvidia-ctk runtime configure --runtime=docker

# 重启 Docker 生效
sudo systemctl restart docker

4.3 验证配置

cat /etc/docker/daemon.json

正常输出应包含 nvidia 运行时配置。

五、Docker 调用 GPU 测试（验证成功）

5.1 基础验证（最常用）

docker run --rm --gpus all nvidia/cuda:13.1.2-base-ubuntu24.04 nvidia-smi

容器内输出和宿主机一致的 GPU 信息 → 环境搭建完成

5.2 CUDA 功能验证

docker run --rm --gpus all nvidia/cuda:13.1.2-devel-ubuntu24.04 \bash -c "apt update && apt install -y cuda-13-1 && /usr/local/cuda-13.1/extras/demo_suite/deviceQuery"

输出 Result = PASS 代表 CUDA 完全可用。

六、Docker GPU 实用玩法

6.1 运行 Ollama 大模型（GPU 加速）

# 启动容器
docker run -d --gpus all -v ollama:/root/.ollama -p 11434:11434 --name ollama ollama/ollama

# 进入运行模型
docker exec -it ollama ollama run llama3

6.2 运行 AI 绘图（Stable Diffusion）

docker run -d --gpus all -p 7860:7860 --name sd-webui \-v $(pwd)/models:/app/models \-v $(pwd)/outputs:/app/outputs \
  AbdBarho/stable-diffusion-webui:latest

访问：http://本机IP:7860

6.3 PyTorch GPU 容器

  1. 新建 Dockerfile
FROM nvidia/cuda:13.1.2-base-ubuntu24.04RUN apt update && apt install -y python3 python3-pipRUN pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124WORKDIR /appCOPY test_gpu.py .CMD ["python3", "test_gpu.py"]
  1. 新建 test_gpu.py
import torch
print("PyTorch 版本:", torch.__version__)print("CUDA 是否可用:", torch.cuda.is_available())if torch.cuda.is_available():print("GPU 名称:", torch.cuda.get_device_name(0))
  1. 构建运行
docker build -t my-gpu-app .docker run --rm --gpus all my-gpu-app

七、常用 GPU 容器命令

  1. 指定使用 GPU 0
docker run --rm --gpus 0 nvidia/cuda:13.1.2-base-ubuntu24.04 nvidia-smi
  1. 使用所有 GPU
docker run --rm --gpus all ...
  1. Docker Compose 配置 GPU
version: '3.8'services:gpu-app:image: nvidia/cuda:13.1.2-base-ubuntu24.04
    deploy:resources:reservations:devices:- driver: nvidia
              count: all
              capabilities: [gpu]

八、常见问题排查

  1. nvidia-smi 无输出：驱动未安装 / 未重启
  2. 容器提示找不到 GPU：未安装 nvidia-container-toolkit 或 Docker 未重启
  3. 权限报错：将用户加入 docker 组
  4. CUDA 版本不兼容：容器内 CUDA 版本不能超过宿主机驱动支持的版本
  5. 如果在线安装报错可以尝试在github里下载安装包
## 下载安装包
wget https://github.com/NVIDIA/nvidia-container-toolkit/releases/download/v1.19.0/nvidia-container-toolkit_1.19.0_deb_amd64.tar.gz

## 解压安装包
tar xf nvidia-container-toolkit_1.19.0_deb_amd64.tar.gz

## 执行安装
cd release-v1.19.0-stable/packages/ubuntu18.04/amd64
sudo dpkg -i *deb
sudo apt install -f

# 自动配置 Docker 运行
sudo nvidia-ctk runtime configure --runtime=docker

# 重启 Docker 生效
sudo systemctl restart docker
