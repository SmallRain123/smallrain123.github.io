Ubuntu 安装 NVIDIA 显卡驱动教程

← 返回知识库

GPU / 驱动#知识库#GPU / 驱动#Ubuntu#NVIDIA

本文适用于 Ubuntu 18.04/20.04/22.04 等主流版本，提供 三种安装方式（官方仓库自动安装、PPA 源安装、手动下载安装），优先推荐新手使用「官方仓库自动安装」，操作最简单且稳定性高。

二、准备工作

2.1 检查系统信息与显卡型号

  • 查看 Ubuntu 系统版本：
lsb_release -a
  • 查看显卡型号（确认 NVIDIA 显卡型号，用于匹配驱动版本）：
lspci | grep -i nvidia
  • 或更直观的方式（需先安装工具）：
sudo apt install hwinfo -y
hwinfo --gfxcard | grep Model
  • 检查当前驱动状态（可选）：
nvidia-smi  # 未安装驱动时会提示命令不存在

2.2 禁用 nouveau 开源驱动（关键步骤）

Ubuntu 默认的 nouveau 开源驱动会与 NVIDIA 闭源驱动冲突，必须先禁用：

  • 编辑黑名单文件：
sudo vim /etc/modprobe.d/blacklist-nouveau.conf
  • 在文件中添加以下内容：
blacklist nouveau
blacklist lbm-nouveau
options nouveau modeset=0
alias nouveau off
alias lbm-nouveau off
  • 更新 initramfs 并重启系统：
sudo update-initramfs -u 
sudo reboot
  • 验证 nouveau 是否禁用（无输出则表示禁用成功）：
lsmod | grep nouveau

三、安装方式（任选其一）

方式 1：官方仓库自动安装（推荐新手）

此方式由 Ubuntu 官方维护，适配性最好，操作最简单：

  • 更新系统软件包：
sudo apt update && sudo apt upgrade -y
  • 安装显卡驱动检测工具：
sudo apt install ubuntu-drivers-common -y
  • 查看推荐安装的驱动版本：
ubuntu-drivers devices
  • 输出示例中 recommended 标注的即为推荐版本（如 nvidia-driver-535）。
  • 自动安装推荐的驱动：
sudo ubuntu-drivers autoinstall
  • 安装完成后重启系统：
sudo reboot

方式 2：PPA 源安装（获取最新驱动）

若需要最新版本的驱动，可通过 NVIDIA 官方 PPA 源安装：

  • 添加 NVIDIA PPA 源：
sudo add-apt-repository ppa:graphics-drivers/ppa
sudo apt update
  • 查看可安装的驱动版本：
apt list | grep nvidia-driver
  • 安装指定版本驱动（以 535 为例）：
sudo apt install nvidia-driver-535 -y
  • 重启系统：
sudo reboot

方式 3：手动下载安装（适合特殊需求）

若上述方式无法满足需求（如特定版本驱动），可手动下载安装包：

  • 前往 NVIDIA 官网下载对应驱动：官网地址：https://www.nvidia.com/Download/index.aspx

    • 选择显卡型号、操作系统（Linux 64-bit）、语言，点击「Search」下载 .run 格式安装包。

  • 安装依赖环境：

sudo apt install gcc make linux-headers-$(uname -r) -y
  • 关闭图形界面（避免安装冲突）：
sudo systemctl stop gdm3  # Ubuntu 20.04/22.04 用 gdm3；18.04 用 lightdm# 切换到 tty 终端（按 Ctrl+Alt+F3），登录账号
  • 赋予安装包执行权限并安装：
chmod +x NVIDIA-Linux-x86_64-535.129.03.run  # 替换为你的安装包名称sudo ./NVIDIA-Linux-x86_64-535.129.03.run
  • 安装过程中按提示操作（默认选项即可），安装完成后重启：
sudo reboot

四、验证安装是否成功

重启后执行以下命令，若输出显卡信息和驱动版本，则安装成功：

nvidia-smi

五、常见问题解决

问题 1：安装后登录界面循环（无法进入系统）

原因：驱动版本不兼容或安装过程中依赖缺失。解决方法：

  • 切换到 tty 终端（Ctrl+Alt+F3），卸载当前驱动：
sudo apt purge nvidia* -y
  • 重新安装推荐版本的驱动（方式 1）。

问题 2：nvidia-smi 提示「NVIDIA-SMI has failed because it couldn’t communicate with the NVIDIA driver」

原因：驱动未正确加载或内核版本不匹配。解决方法：

  • 检查内核版本与驱动兼容性，安装对应版本的 linux-headers：
sudo apt install linux-headers-$(uname -r) -y
  • 重新生成驱动模块：
sudo depmod -a
sudo modprobe nvidia

问题 3：手动安装时提示「Secure Boot」相关错误

原因：系统开启了 Secure Boot，阻止非签名驱动加载。解决方法：

  • 进入 BIOS 关闭 Secure Boot；
  • 或在安装驱动时选择「Sign the kernel module」并设置密码，后续按提示完成签名。

六、卸载 NVIDIA 驱动

若需要卸载驱动，执行以下命令：

# 方式 1/2 安装的驱动卸载sudo apt purge nvidia* -ysudo apt autoremove -y# 方式 3 手动安装的驱动卸载sudo /usr/bin/nvidia-uninstall

总结

  1. 安装前必须禁用 nouveau 驱动，这是避免冲突的核心步骤；
  2. 新手优先选择「官方仓库自动安装」，稳定性最高，操作最简单；
  3. 验证安装是否成功的核心命令是 nvidia-smi，能输出显卡和驱动信息即表示安装完成
