Docker Plugin 实用手册

← 返回知识库

Docker / 容器#知识库#Docker / 容器#Docker

Docker Plugin（插件）用于扩展 Docker 能力：日志驱动、存储卷、网络、授权等。插件本质是独立进程，由 dockerd 管理。 ⚠️ 注意：Docker Plugin 和 compose 插件不是一回事；docker compose 是 CLI 插件。

一、基础语法

# 查看本地已安装插件
docker plugin ls

# 拉取插件（从Docker Hub）
docker plugin pull <plugin-name>

# 启用插件（拉取完默认disable，必须enable）
docker plugin enable <plugin-name>

# 禁用插件
docker plugin disable <plugin-name>

# 删除插件（必须先disable）
docker plugin rm <plugin-name>

# 查看插件详细信息（类似docker inspect）
docker plugin inspect <plugin-name>

插件命名格式：repo/name:tag，如 grafana/loki-docker-driver

二、插件生命周期完整示例（日志驱动插件举例）

以 loki 日志插件为例

#1 拉取插件
docker plugin pull grafana/loki-docker-driver:latest

#2 配置插件参数（按需）
docker plugin set grafana/loki-docker-driver:latest \
  loki-url=http://loki:3100/loki/api/v1/push

#3 启用插件
docker plugin enable grafana/loki-docker-driver:latest

#4 查看插件详情
docker plugin inspect grafana/loki-docker-driver:latest

#5 使用插件启动容器（指定log-driver）
docker run -d --name test-log \
  --log-driver=grafana/loki-docker-driver:latest \
  --log-opt loki-url="http://loki:3100/loki/api/v1/push" \
  nginx

#6 停用 + 删除（卸载必须先disable）
docker plugin disable grafana/loki-docker-driver:latest
docker plugin rm grafana/loki-docker-driver:latest

三、docker plugin inspect 模板（重点，和容器 inspect 类似）

# 查看插件是否启用
docker plugin inspect --format 'Enabled={{.Enabled}}' grafana/loki-docker-driver:latest

# 查看插件支持能力（日志/网络/卷）
docker plugin inspect --format '{{.Config.Interface.Types}}' grafana/loki-docker-driver:latest

# 查看插件环境变量
docker plugin inspect --format '{{.Config.Env | json}}' grafana/loki-docker-driver:latest

# 一键汇总
docker plugin inspect --format '
====插件信息====
名称:{{.Name}}
启用状态:{{.Enabled}}
插件版本:{{.PluginVersion}}
====配置====
接口类型:{{.Config.Interface.Types}}
环境变量:{{.Config.Env}}
' grafana/loki-docker-driver:latest

四、Docker 常用插件分类

Logging 日志驱动插件（最常用）

  • grafana/loki-docker-driver：容器日志推送 Loki
  • elastic/elastic-logstash-driver：日志推 ES/Logstash 使用方式：--log-driver=插件名

Volume 存储插件

  • rexray/rexray：对接云存储、NAS，外部持久卷
  • netapp/ontap：Netapp 存储

作用：docker volume create -d 插件名 创建外部存储卷

# 使用存储插件创建volume
docker volume create -d rexray/rexray:latest my-volume

Network 网络插件

Calico、Weave 早期提供 docker plugin 网络驱动；现在大多改用 CNI。

授权插件（企业安全）

限制容器创建、资源访问权限，生产企业环境。

五、全局 daemon.json 加载插件（全局生效）

/etc/docker/daemon.json，全局默认日志驱动示例：

{
  "log-driver": "grafana/loki-docker-driver:latest",
  "log-opts": {
    "loki-url": "http://127.0.0.1:3100/loki/api/v1/push"
  }
}

修改后重启 docker

systemctl daemon-reload
systemctl restart docker

⚠️ 插件必须先enable，否则 dockerd 启动失败！

六、排错指南（高频坑）

  1. 插件 enable 失败

    • 网络无法拉取镜像 / 插件依赖缺失
    • 安全限制：selinux/apparmor 拦截插件挂载
    • 旧版 docker 不支持该插件版本

  2. 容器启动报错：unknown log driver

    • 插件未 enable；插件名写错；插件被删除
docker plugin ls #确认插件存在+Enabled=true
  1. 卸载报错：plugin in use

容器 /volume 正在使用插件，必须先停所有使用该插件的容器，再 disable 插件，才能 rm

#查找正在使用该日志驱动的容器
docker ps -a --format '{{.Names}} {{.LogDriver}}'
  1. dockerd 无法启动，daemon.json 指定的插件不可用 临时修复：修改 daemon.json 换回json-file，重启 docker。

七、区分 2 个容易混淆概念（必看）

  1. Docker Plugin（引擎插件）：docker plugin命令管理，扩展 dockerd 底层能力（日志、存储、网络），dockerd 层面加载。
  2. CLI 插件（如 docker compose）：属于 docker 客户端扩展，不属于 docker plugin 子命令管理。

docker compose不是docker plugin，不要用docker plugin ls去找 compose。

八、常用一键脚本

#列出全部插件+启用状态
docker plugin ls

#批量查看所有插件详细状态
docker plugin ls --format '{{.Name}}' | xargs -I {} sh -c "echo ===== {} =====; docker plugin inspect --format 'Enabled={{.Enabled}}' {}"

九、生产最佳实践

  1. 生产环境慎用第三方插件，插件崩溃会直接导致 dockerd 异常。
  2. 插件升级前先备份配置，停掉依赖插件的容器。
  3. 不要随意全局设置存储 / 日志插件，一旦插件故障所有容器无法启动。
  4. 插件版本锁定，不要使用 latest 标签。
