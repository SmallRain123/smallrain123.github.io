Ubuntu 从新手到入门学习指南

← 返回知识库

Linux / 系统#知识库#Linux / 系统#Ubuntu

这份指南为零基础读者设计：从完全不了解 Linux 的状态出发，用 2～4 周时间，掌握 Ubuntu 的安装、日常使用和终端基本功，达到能独立使用 Ubuntu 的水平。文中命令以 Ubuntu 26.04 LTS 为例，同样适用于 24.04、22.04 LTS。

学习原则：动手优先，边学边练。每条命令都亲手敲一遍，比看十遍教程更有效；遇到问题先自己搜索排查，再向社区求助。

学习路径总览

从新手到入门共六个阶段，每个阶段都有明确目标和完成标志。建议按顺序推进，不要跳步；每完成一个阶段就停下来验证成果。

认识 Ubuntu 与学习准备

Ubuntu 是什么

Ubuntu 是基于 Linux 内核的开源操作系统，由 Canonical 公司维护，是目前全球使用最广泛的 Linux 发行版之一。它免费、开放、安全，广泛用于个人桌面、服务器、云计算和人工智能开发。

  • 开源免费：系统本身和绝大多数软件免费，可自由使用和修改。
  • 版本体系：每 6 个月发布一个普通版；每 2 年发布一个 LTS（长期支持）版本，提供 5 年标准安全维护。
  • 生态成熟：软件仓库拥有数万个软件包，几乎可以替代 Windows 的日常用途。

选择版本

对新手来说，只认准 LTS 版本即可：稳定、支持期长、教程资料最多。截至 2026 年 9 月，正在维护的 LTS 版本有 26.04、24.04、22.04。

你的情况 推荐版本 说明
新手 / 日常使用 / 服务器 Ubuntu 26.04 LTS 2026 年 4 月发布，标准支持至 2031 年，功能最新
追求更成熟稳定 Ubuntu 24.04 LTS 已发布两年多，生态适配完善，教程最多
想尝鲜新功能 最新普通版 每 6 个月一版，仅 9 个月支持，不建议新手日常用
电脑配置较低 Xubuntu / Lubuntu Ubuntu 官方衍生版，轻量桌面，适合旧机器

学习前的准备

  1. 确认硬件：4GB 以上内存、25GB 以上磁盘空间即可流畅运行桌面版；配置越高体验越好。
  2. 备份数据：如果计划安装双系统，先备份 Windows 中的重要文件，并确认电脑支持从 U 盘启动。
  3. 选择上手方式：新手建议先用虚拟机（不影响现有系统），熟悉后再决定是否实体机安装。
  4. 准备好网络：安装和后续软件下载都依赖网络，最好能连上稳定的互联网。

第一步：安装 Ubuntu

目标：在电脑上装出一个能正常进入桌面的 Ubuntu 系统。全程约 20～40 分钟。

选择安装方式

方式 适合人群 说明
虚拟机 新手首选、想先体验 在 Windows 里用 VMware / VirtualBox 运行 Ubuntu，不碰现有系统，随时可删
双系统 想长期使用、需要性能 与 Windows 共存，开机选择进入哪个系统；需预留磁盘分区
WSL 开发为主、不想装图形界面 Windows 自带的 Linux 子系统，命令行体验，适合学习终端和开发
整机安装 专用机器、熟悉后 彻底替换原系统，性能最佳，适合以后专机专用

制作启动盘或创建虚拟机

  1. 访问 Ubuntu 官网下载对应 LTS 版本的 ISO 镜像文件（约 5GB）。
  2. 实体机安装：用 Rufus 或 balenaEtcher 把 ISO 写入 U 盘，制作启动盘。
  3. 虚拟机安装：在 VMware / VirtualBox 中新建虚拟机，选择下载好的 ISO 作为安装镜像。
  4. 重启电脑进入 U 盘启动（或启动虚拟机），选择「试用或安装 Ubuntu」。

安装过程要点

  1. 语言与键盘：按需选择简体中文和默认键盘布局。
  2. 磁盘分区：新手选「清除整个磁盘并安装 Ubuntu」最省心；想保留 Windows 则选「与 Windows 共存」，安装器会自动分区。
  3. 账号设置：设置用户名和密码。请记住密码，后续安装软件、系统更新都要用到。
  4. 完成安装：等待安装进度条走完，重启并移除安装介质。
阶段验证：能正常进入桌面、看到欢迎界面、联网成功，即视为安装阶段完成。

第二步：熟悉桌面环境

目标：像使用 Windows 一样完成日常操作——上网、办公、装软件、更新系统。

GNOME 桌面基础操作

  • 活动视图：按 Super 键（Windows 键）打开总览，可搜索应用、切换窗口。
  • 顶栏与 Dock：顶栏显示时间、网络、音量；左侧 Dock 可固定常用应用。
  • 系统设置：在「设置」中调整显示、网络、声音、电源等。
  • 常用快捷键：Ctrl+Alt+T 打开终端；Super+A 显示全部应用；Super+L 锁屏。

文件系统与目录结构

Linux 采用单一根目录树，所有文件都从 / 开始，没有 Windows 那样的 C 盘、D 盘。理解目录结构是入门的关键一步。

目录 作用
/home 普通用户的个人目录，你的文档、图片、下载都在这（如 /home/你的用户名）
/etc 系统配置文件目录，如软件源、网络配置
/usr 系统安装的软件和共享文件
/var 经常变化的数据，如日志（/var/log）、缓存
/tmp 临时文件，重启后通常被清空
/bin、/sbin 系统基本命令和系统管理命令
/opt 第三方商业软件安装位置

安装软件的三种方式

  1. 软件中心（图形化）：打开「Ubuntu 软件」应用，搜索、点击安装，适合新手。
  2. apt 命令：从软件仓库安装，是 Ubuntu 最核心的安装方式，详见后续章节。
  3. deb 包 / Snap：从官网下载 .deb 文件双击安装；Snap 是 Canonical 推广的跨发行版打包格式，命令为 sudo snap install 包名。

系统更新与软件升级

Ubuntu 不会强制弹窗升级，建议每周手动更新一次，保持系统安全和稳定。

sudo apt update

sudo apt upgrade
阶段验证：能安装一个软件（如浏览器）、完成一次系统更新，即视为通过。

第三步：掌握终端基础

目标：理解终端的工作方式，用命令行完成文件管理、权限和进程等常见操作。终端是 Linux 的”灵魂”，也是进一步学习服务器、开发、运维的必经之路。

打开终端与命令格式

按 Ctrl+Alt+T 打开终端。命令的基本格式是「命令 + 选项 + 参数」，例如 ls -l /home 表示以详细列表方式查看 /home 目录。可用 命令 --help 查看帮助，用 Tab 键自动补全，用上下方向键翻看历史命令。

文件与目录常用命令

命令 作用 示例
pwd 显示当前所在目录 pwd
ls 列出目录内容；-l 详细、-a 含隐藏文件 ls -la
cd 切换目录；.. 上级、~ 家目录 cd /etc
mkdir 创建目录 mkdir myproject
touch 创建空文件 touch note.txt
cp 复制文件或目录（-r 递归） cp a.txt b.txt
mv 移动或重命名 mv a.txt docs/
rm 删除；-r 递归删目录，-f 强制 rm -rf tmp/
cat 查看文件全部内容 cat note.txt
less 分页查看大文件，q 退出 less /var/log/syslog
grep 在文件中搜索关键词 grep error log.txt
危险动作提醒：`rm -rf` 会静默删除且不可恢复，执行前务必确认路径正确，不要在重要目录（如 /home）下随手使用。

文件权限与 sudo

  • 权限位：ls -l 第一列如 rwxr-xr-x 表示 属主/属组/其他用户 的读、写、执行权限。
  • 修改权限：chmod 755 文件名 用数字修改权限，如 chmod +x 脚本.sh 给文件加执行权限。
  • sudo 提权：以管理员身份执行命令。日常操作不需要 sudo，只有改系统配置、装软件时才用，避免权限滥用。

查看系统信息与进程

命令 作用
uname -a 查看内核与系统版本信息
df -h 查看磁盘空间使用情况
free -h 查看内存使用情况
top / htop 实时查看进程与资源占用，q 退出
ps aux 列出当前所有进程
ip a 查看网卡和 IP 地址
阶段验证：能不看笔记完成新建目录、复制文件、查看磁盘和内存、用 grep 搜索日志，即视为通过。

第四步：日常使用进阶

目标：解决实际使用中的真实问题——装软件、管用户、远程连接、排查故障。

软件包管理深入

命令 作用
sudo apt update 更新软件源索引（装软件前先执行）
sudo apt install 包名 安装软件
sudo apt remove 包名 卸载软件（保留配置文件）
sudo apt purge 包名 彻底卸载（连同配置）
apt search 关键词 搜索软件仓库
apt show 包名 查看软件包详细信息
sudo apt autoremove 清理不再需要的依赖包

如果官方源下载慢，可把软件源换成国内镜像（清华、阿里云、中科大），修改 /etc/apt/sources.list 后执行 sudo apt update。

用户与权限管理

  • 查看当前用户：whoami
  • 添加用户：sudo adduser 用户名
  • 修改密码：passwd（改自己的）/ sudo passwd 用户名（改别人的）
  • 授予管理员权限：sudo usermod -aG sudo 用户名
  • 切换用户：su - 用户名

远程连接：SSH

SSH 是 Linux 远程管理的标配。让另一台电脑通过网络命令行远程操作 Ubuntu，是学习服务器运维的第一步。

  1. 在目标机器上安装并启动 SSH 服务：sudo apt install openssh-server，然后 sudo systemctl enable --now ssh。
  2. 查看目标机器的 IP：ip a。
  3. 在本地电脑连接：ssh 用户名@IP地址，输入密码即可登录。

常见问题排查

问题 解决办法
忘了登录密码 重启进入 GRUB 菜单，选「高级选项 → 恢复模式」，在 root 终端执行 passwd 用户名 重置
apt 安装报错 先执行 sudo apt update；仍报错则 sudo apt --fix-broken install 修复依赖
软件源下载慢 更换为国内镜像源（清华 TUNA、阿里云等）
命令提示找不到 用 apt search 关键词 找到对应软件包并安装
系统突然卡顿 用 top 查看占用高的进程，kill 进程号 结束异常进程
上不了网 检查网卡 ip a、网络设置；有线无网络可先尝试 sudo systemctl restart NetworkManager
阶段验证：能用 apt 安装卸载软件、新增一个用户、通过 SSH 远程登录，即视为通过。

入门自测与下一步方向

入门自测清单

逐项勾选，全部能独立完成即达到「入门」水平。

  • 能说出 Ubuntu 与 Windows 的主要区别，以及 LTS 版本的含义

  • 能独立完成一次 Ubuntu 安装（虚拟机或实体机均可）

  • 能在桌面完成文件管理、软件安装和系统更新

  • 能说明 /home、/etc、/usr、/var 等目录的主要作用

  • 能熟练使用 10 个以上常用终端命令完成文件操作

  • 理解文件权限 rwx 的含义，能使用 sudo 和 chmod

  • 能用 apt 完成软件的搜索、安装、卸载

  • 能通过 SSH 远程连接另一台 Ubuntu 主机

  • 遇到问题时能自己搜索资料并描述清楚问题

新手常见坑

  • 盲目使用 sudo：能用普通权限就别加 sudo，系统文件改错了很难恢复。
  • 随意执行网上复制的命令：尤其是带 rm、curl | bash 的脚本，先看懂再执行。
  • 分区时选错磁盘：双系统安装分区时看清盘符，避免误清数据。
  • 只记命令不理解原理：命令会过时，理解文件系统、权限、进程等概念才能举一反三。

学习资源推荐

资源 说明
Ubuntu 官方文档 documentation.ubuntu.com，最权威的官方手册，涵盖桌面、服务器全场景
Ubuntu 中文社区 / 论坛 中文问答与教程聚集地，遇到问题优先搜索
《鸟哥的 Linux 私房菜》 华语最经典的 Linux 入门书，基础篇特别适合新手通读
终端练习网站 Linux Journey、Command Challenge 等在线交互练习，边玩边学
动手小项目 搭一个 LAMP（Linux+Apache+MySQL+PHP）网站、搭建 NAS、配置 SSH 密钥登录，用项目巩固知识
入门之后往哪走：想搞开发 → 学 Vim、Git、Docker；想搞运维 → 学 Shell 脚本、systemd、Nginx；想搞 AI/数据 → 学 Python、CUDA 环境配置。Ubuntu 打好基础后，这些方向都顺理成章。
