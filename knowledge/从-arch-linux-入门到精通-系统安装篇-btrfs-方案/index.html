从 Arch Linux 入门到精通：系统安装篇 (Btrfs 方案)

← 返回知识库

Linux / 系统#知识库#Linux / 系统#Arch#Linux

Arch Linux 以其简洁、轻量和高度可定制性著称，是许多高级 Linux 用户的选择。本文将详细介绍如何从零开始安装 Arch Linux，特别采用包含 Boot (EFI)、Swap 和 Btrfs 根分区 的方案。Btrfs 文件系统提供了高级功能如写时复制(CoW)、快照和子卷管理，非常适合系统备份与恢复。

1. 准备工作

1.1 下载 Arch Linux 镜像

访问 Arch Linux 官方下载页面获取最新镜像，并制作启动盘（推荐使用 dd 或 Ventoy 等工具）。

1.2 启动 Live 环境

将启动盘插入电脑，从 USB 启动进入 Arch Linux Live 环境。您将看到一个命令行提示符。

2. 基础设置

2.1 连接网络

有线网络（通常会自动通过 dhcpcd 获取IP）：

dhcpcd

无线网络（使用 iwctl）：

iwctl
[iwd]# station wlan0 scan
[iwd]# station wlan0 get-networks
[iwd]# station wlan0 connect <SSID>
[iwd]# exit

2.2 更新系统时钟

确保系统时钟准确：

timedatectl set-ntp true

2.3 分区与格式化（Btrfs 方案）

本指南使用以下分区结构：

  • /dev/sda1：EFI 系统分区 (ESP) - 512MB
  • /dev/sda2：Swap 分区 - 大小根据您的内存决定（例如 16GB）
  • /dev/sda3：Btrfs 根分区 - 占用剩余所有空间

使用 fdisk 或 cfdisk 进行分区（以 /dev/sda 为例）：

cfdisk /dev/sda

在 cfdisk 中：

  1. 选择 gpt 标签类型（适用于 UEFI 系统）。

  2. 创建新分区 (New)：

    • 第一个分区：大小 512M，类型为 EFI System。
    • 第二个分区：大小例如 16G，类型为 Linux swap。
    • 第三个分区：使用剩余所有空间，类型为 Linux filesystem。

  3. 将分区表写入磁盘 (Write)。

格式化分区：

# 格式化 EFI 分区为 FAT32
mkfs.fat -F32 /dev/sda1

# 格式化 Swap 分区并启用
mkswap /dev/sda2
swapon /dev/sda2

# 格式化根分区为 Btrfs
mkfs.btrfs -f /dev/sda3

2.4 创建 Btrfs 子卷并挂载

Btrfs 的强大功能在于子卷。我们将为根目录和家目录创建单独的子卷，方便以后做快照。

挂载 Btrfs 根分区：

mount /dev/sda3 /mnt

创建 Btrfs 子卷：

# 创建 @ 子卷作为根目录
btrfs subvolume create /mnt/@
# 创建 @home 子卷作为家目录
btrfs subvolume create /mnt/@home
# 创建 @snapshots 子卷用于存放系统快照（可选但推荐）
btrfs subvolume create /mnt/@snapshots
# 创建 @var_log 子卷隔离日志（可选）
btrfs subvolume create /mnt/@var_log
      
# 卸载根分区以重新挂载子卷
umount /mnt

使用子卷选项重新挂载：

mount -o subvol=@,compress=zstd,noatime /dev/sda3 /mnt

# 创建必要的目录结构mkdir -p /mnt/{boot,home,.snapshots,var/log}

# 挂载其他子卷和分区
mount -o subvol=@home,compress=zstd,noatime /dev/sda3 /mnt/home
mount -o subvol=@snapshots,compress=zstd,noatime /dev/sda3 /mnt/.snapshots
mount -o subvol=@var_log,compress=zstd,noatime /dev/sda3 /mnt/var/log

# 挂载 EFI 分区
mount /dev/sda1 /mnt/boot

挂载参数说明：

  • subvol=@：指定要挂载的子卷。
  • compress=zstd：使用高效的 zstd 算法透明压缩数据，节省空间。
  • noatime：禁止更新文件的访问时间，减少磁盘写入，提升性能。

3. 安装系统

3.1 选择镜像源

编辑pacman.conf文件，方便加速下载。


# 或者修改pacman.conf文件
sed -i 's/ParallelDownloads = 5/ParallelDownloads = 100/g' /etc/pacman.conf
echo "[archlinuxcn]" >> /etc/pacman.conf
echo "Server = https://mirrors.tuna.tsinghua.edu.cn/archlinuxcn/\$arch" >> /etc/pacman.conf

# 也可以更改成其他的
Server = https://mirrors.aliyun.com/archlinuxcn/\$arch

# 安装archlinuxcn-keyring
pacman -Sy archlinuxcn-keyring

3.2 安装基础包

使用 pacstrap 脚本安装最基本的软件包到新系统，包括 Linux 内核、硬件固件、文本编辑器和网络工具。

pacstrap -K /mnt base base-devel linux linux-firmware sof-firmware btrfs-progs nano sudo networkmanager git

包说明：

  • base, base-devel：基础系统和编译工具组。
  • linux：Linux 内核。
  • linux-firmware：硬件设备固件。
  • btrfs-progs：Btrfs 文件系统管理工具。
  • sudo, vim：权限管理和文本编辑器。
  • networkmanager：网络连接管理工具。

4. 系统配置

4.1 生成 Fstab 文件

生成自动挂载文件系统表 (fstab)。使用 -U 选项通过 UUID 挂载，比设备名 (/dev/sdaX) 更稳定。

genfstab -U /mnt >> /mnt/etc/fstab

检查生成的 /mnt/etc/fstab 文件，确保所有挂载点（尤其是 Btrfs 子卷）正确无误。

4.2 Chroot 到新系统

使用 arch-chroot 脚本切换到新安装的系统进行配置。

arch-chroot /mnt

4.3 设置时区与本地化

# 设置时区（以上海为例）ln -sf /usr/share/zoneinfo/Asia/Shanghai /etc/localtime
hwclock --systohc

# 本地化设置，编辑 /etc/locale.gen，取消注释 en_US.UTF-8 UTF-8 和其他需要的 locale
vim /etc/locale.gen
locale-gen

# 创建 locale.conf 文件并设置 LANG 变量echo "LANG=en_US.UTF-8" > /etc/locale.conf

4.4 网络配置

设置主机名：

echo "myarch" > /etc/hostname

编辑 /etc/hosts 文件：

127.0.0.1   localhost
::1         localhost
127.0.1.1   myarch.localdomain myarch

启用 NetworkManager 服务（安装图形界面后也可使用 nmtui 或 nmcli）：


systemctl enable NetworkManager

4.5 设置 Root 密码并创建用户

# 设置 root 密码
passwd

# 创建一个新用户（例如 username）并加入 wheel 组（用于 sudo）
useradd -m -G wheel -s /bin/bash username
passwd username

# 编辑 sudoers 文件，为 wheel 组授予 sudo 权限
EDITOR=vim visudo
# 找到此行并取消注释# %wheel ALL=(ALL:ALL) ALL

4.6 安装引导程序 (Bootloader)

我们使用 GRUB 作为引导程序。

# 安装必要的包
pacman -S grub efibootmgr os-prober

# 安装 GRUB 到 EFI 分区
grub-install --target=x86_64-efi --efi-directory=/boot --bootloader-id=GRUB

# 生成 GRUB 配置文件
grub-mkconfig -o /boot/grub/grub.cfg

如果之后需要检测其他操作系统（如 Windows），请安装 os-prober 并重新生成配置。

5. 完成安装

# 退出 chroot 环境exit# 卸载所有挂载的分区
umount -R /mnt

# 重启系统
reboot

重启后，拔出安装介质，您应该可以看到 GRUB 引导界面，选择 Arch Linux 启动。使用您创建的用户名和密码登录。

6. 后续步骤（安装后建议）

  1. 连接网络： 使用 nmtui 命令启动文本界面配置 Wi-Fi 或有线连接。
  2. 安装图形界面： 安装 Xorg 服务器和您喜欢的桌面环境（如 KDE Plasma, GNOME, Xfce）或窗口管理器（如 i3, Sway）。
  3. 安装显卡驱动： 根据您的显卡（Intel, AMD, NVIDIA）安装对应的驱动。
  4. 安装声音管理： pacman -S alsa-utils pulseaudio pulseaudio-alsa（或 pipewire）。
  5. 探索 AUR： 安装 yay 或 paru 等 AUR 助手来获取丰富的社区软件包。

恭喜！您已经成功安装了一个基于 Btrfs 的 Arch Linux 系统。现在您可以开始探索和定制您的强大工作站了

命令行安装系统

系统分区：

使用cdisk进行分区，推荐boot使用1G ,然后剩下的给根目录

格式化分区：

# 格式化sda1分区，格式为fat F32
mkfs.fat -F 32 /dev/sda1

# 格式化btrfs
mkfs.btrfs -f /dev/sda2

创建btrfs子卷：

# 挂在分区
mount -t btrfs -o compress=zstd /dev/sda2 /mnt

# 创建子卷
btrfs subvolume create /mnt/@
btrfs subvolume create /mnt/@home
btrfs subvolume create /mnt/@swap

#查看子卷
btrfs subvolume list -p /mnt

# 卸载分区
umount -R /mnt

挂载btrfs子卷：

mount -t btrfs -o subvol=/@,compress=zstd /dev/sda2 /mnt  # 挂载根目录
mount --mkdir -t btrfs -o subvol=/@home,compress=zstd /dev/sda2 /mnt/home  # 挂载家目录，如果没有就创建
mount --mkdir -t btrfs -o subvol=/@swap,compress=zstd /dev/sda2 /mnt/swap  # 挂载交换分区，如果没有就创建
mount --mkdir /dev/sda1 /mnt/boot # 挂载boot目录

安装基础依赖：

pacstrap -K /mnt base base-devel linux linux-firmware btrfs-progs

安装必装软件：

pacstrap -K /mnt sudo vim networkmanager

生成fstab：

genfstab -U /mnt > /mnt/etc/fstab

配置引导：

pacman -S grub efibootmgr  # 安装graub和efibootmgr

# 安装引导
grub-install --target=x86_64-efi --efi-diretory=/boot --bootloader-id=GRUB

# 更新
grub-mkconfig -o /mnt/boot/grub/grub.cfg

配置时区：

ln -sf /usr/sahre/zone

arch-chroot /mnt
