All-in-One (AIO) 实战教程

← 返回知识库

AI / 工具#知识库#AI / 工具

本教程基于当前最主流、最稳定的技术栈：底层 PVE 8.x + 主路由 iKuai (爱快) + 旁路由 OpenWrt/iStoreOS + Docker/NAS 服务。旨在帮助您用一台小主机取代路由器、NAS、下载机和电视盒子，实现“一机搞定全家网络”。

🚀 软路由 All-in-One (AIO) 终极指南：从入门到精通 (2026版)

📅 更新时间：2026-03-20

💡 核心理念：拒绝“All-in-Boom”（一崩全崩），构建高可用、易维护的家庭网络中心。

⏱️ 预计耗时：1.5 - 2 小时

🎯 适用硬件：多网口 x86 小主机 (推荐 N100, N305, 或二手 J4125/J6412)

1. 准备工作 (Prerequisites)

在开始之前，请确保您拥有以下硬件和软件资源。

🛠️ 硬件清单

设备 要求 说明
软路由主机 至少 2 个网口 (推荐 4 个 2.5G 网口) 核心设备，推荐搭载 Intel N100/N305 处理器
U 盘 容量 ≥ 8GB 用于制作启动安装盘
显示器 & 键盘 任意 仅安装系统时临时使用，后续可拔掉
网线 超五类或六类线 至少 2 根，建议准备 4 根

💾 软件镜像下载

请提前下载以下 ISO 镜像文件到电脑本地：

  1. Ventoy (制作启动盘工具): 官网下载
  2. Proxmox VE (PVE) 8.x ISO: 官方下载
  3. iKuai (爱快) ISO: 官方下载
  4. OpenWrt / iStoreOS ISO: 推荐下载恩山论坛编译版或 iStoreOS 官方镜像

2. 第一步：制作启动盘与安装 PVE

PVE (Proxmox Virtual Environment) 是整个 AIO 的基石，它负责管理所有虚拟机。

2.1 制作 Ventoy 启动盘

  1. 插入 U 盘，运行 Ventoy2Disk.exe。
  2. 点击 “安装” (注意：这会格式化 U 盘，请备份数据)。
  3. 安装完成后，直接将下载好的 PVE ISO、iKuai ISO、OpenWrt ISO 三个文件复制到 U 盘根目录。

图 1：将多个 ISO 直接复制到 U 盘即可，无需反复刻录

2.2 安装 PVE 系统

  1. 将 U 盘插入软路由主机，连接显示器和键盘，开机。

  2. 连续按 F11 或 Del 进入启动菜单，选择您的 U 盘 (UEFI: Ventoy)。

  3. 在 Ventoy 菜单中选择 Proxmox VE Installer。

  4. 按照向导操作：

    • Install Proxmox VE -> 同意协议。

    • 目标硬盘：选择您的主机内置硬盘 (数据将被清空！)。

    • 国家/时区：选择 China / Asia/Shanghai。

    • 密码设置：设置 root 用户的密码 (请务必记牢！)。

    • 网络配置：

      • Hostname: 例如 pve.home
      • IP Address: 设置一个固定内网 IP (如 192.168.1.2)，不要与主路由冲突。
      • Gateway: 指向您现有的主路由网关 (如 192.168.1.1)。

  5. 安装完成后重启，拔掉 U 盘。

💡 小贴士：安装成功后，您可以在同一局域网的另一台电脑浏览器输入 https://192.168.1.2:8006 访问 PVE 管理后台。忽略证书警告即可。

3. 第二步：部署主路由 iKuai (爱快)

iKuai 以其强大的流控和稳定性著称，非常适合作为 AIO 的主路由负责拨号和流量分发。

3.1 上传镜像与创建虚拟机

  1. 登录 PVE 后台，点击左侧节点名 -> local (pve) -> ISO Images -> Upload，上传 iKuai ISO。

  2. 点击右上角 创建虚拟机 (Create VM)：

    • VM ID: 100
    • 名称: iKuai-Master
    • ISO 镜像: 选择刚才上传的 iKuai 镜像。
    • 系统: 默认 (Linux 6.x - 2.6 Kernel)。
    • 磁盘: 大小给 4GB 即可 (精简格式)。
    • CPU: 核心数 2 (根据硬件调整)。
    • 内存: 1024 MB (1G 足够)。
    • 网络: 桥接模式，选择您的 WAN 口对应的物理网卡 (例如 enp2s0)。

3.2 关键步骤：添加第二张网卡 (LAN)

iKuai 需要至少两张网卡 (WAN 和 LAN)。

  1. 虚拟机创建完成后，点击该虚拟机 -> 硬件 (Hardware)。
  2. 点击 添加 (Add) -> 网络设备 (Network Device)。
  3. 桥接 (Bridge): 选择 vmbr0 (或者您希望作为 LAN 口的物理网卡，如 enp3s0)。
  4. 模型: 推荐 VirtIO (半虚拟化)。

3.3 安装与配置

  1. 点击 控制台 (Console) 启动虚拟机。

  2. 等待安装完成，输入 y 确认安装到硬盘。

  3. 安装重启后，界面会显示：

    • LAN1: IP 地址 (例如 192.168.10.1)
    • WAN1: DHCP 获取中…

  4. 物理接线：

    • 将光猫/入户网线插入 WAN 口 对应的物理网口。
    • 将电脑/交换机插入 LAN 口 对应的物理网口。

  5. 电脑浏览器访问 iKuai 的 LAN 口 IP (如 192.168.10.1)，进行初始化设置 (PPPoE 拨号等)。

图 2：iKuai 接管拨号，负责整个家庭网络的流量分发

4. 第三步：部署旁路由 OpenWrt / iStoreOS

OpenWrt 负责进阶功能：去广告、科学上网、Docker 容器管理等。

4.1 创建虚拟机

  1. 在 PVE 中重复创建虚拟机的步骤：

    • 名称: OpenWrt-Plus
    • CPU: 2 核心。
    • 内存: 512MB - 1024MB。
    • 磁盘: 2GB - 4GB。
    • 网络: 关键！ 这里只添加一张网卡，桥接到 vmbr0 (即 iKuai 的 LAN 侧网络)。

4.2 配置 OpenWrt

  1. 启动虚拟机，进入控制台。

  2. 输入命令修改 IP (假设 iKuai 网关是 192.168.10.1)：(注：新版 iStoreOS 通常有图形化初始化界面，可直接在网页设置)

    vi /etc/config/network
# 找到 config interface 'lan'
# 修改 option ipaddr '192.168.10.2'  (确保不与 iKuai 冲突)
# 修改 option gateway '192.168.10.1'  (指向 iKuai)
# 修改 option dns '192.168.10.1'      (或公共 DNS 223.5.5.5)

  3. 重要设置：

    • 登录 OpenWrt 后台 (192.168.10.2)。
    • 进入 网络 -> 接口 -> LAN -> 编辑。
    • 防火墙设置：勾选 “忽略此接口” (防止双重 NAT 和防火墙冲突)。
    • 保存并应用。

4.3 流量引流

回到 iKuai 后台：

  1. 进入 网络设置 -> 内外网设置 -> 网关设置。
  2. 添加自定义网关，填写 OpenWrt 的 IP (192.168.10.2)。
  3. 进入 行为管理 -> 分流设置 -> 端口分流 (或智能分流)。
  4. 设置规则：将所有流量 (或特定设备) 的网关指向 OpenWrt。

5. 第四步：扩展玩法 (Docker & NAS)

AIO 的魅力在于无限扩展。您可以在 PVE 中再创建一个 Linux 虚拟机 (如 Debian/Ubuntu) 或直接使用 LXC 容器 来运行 Docker。

5.1 推荐方案：轻量级 Debian 容器

  1. 在 PVE 右键节点 -> 创建 CT (容器)。

  2. 模板选择 debian-12-standard。

  3. 勾选 特权容器 (Privileged container) (方便挂载硬盘)。

  4. 在网络中勾选 桥接。

  5. 启动后，一键安装 Docker：

    curl -fsSL https://get.docker.com | bash

5.2 常见容器应用

您可以轻松部署以下服务：

应用 用途 Docker 命令示例

Jellyfin 家庭影院 利用 N100 核显硬解 4K

6. ⚠️ 避坑指南：如何拒绝 “All-in-Boom”

很多新手担心“软路由挂了全家断网”，以下是稳定运行的核心秘诀：

✅ 1. 物理隔离与备份

  • 保留旧路由：在调试期间，不要扔掉旧路由器。如果 AIO 配置错误，随时可以插回旧路由恢复网络。
  • UPS 电源：强烈建议配备一个小型 UPS (不间断电源)，防止意外断电导致磁盘损坏。

✅ 2. 定期备份 (PVE 核心功能)

  • 在 PVE 中，对 iKuai 和 OpenWrt 虚拟机设置 自动备份。
  • 路径：数据中心 -> 备份 -> 添加。
  • 设置每天凌晨 3 点备份，存储位置可以是外接 USB 硬盘或另一台 NAS。
  • 一旦系统崩溃，可在 5 分钟内从备份恢复！

✅ 3. 散热与硬件

  • N100 等芯片虽然功耗低，但积热严重。确保小主机风道通畅，必要时加装静音风扇。
  • 不要将软路由放在微波炉、打印机等强干扰源旁边，这会导致 WiFi (如果使用了无线网卡) 或 2.5G 网口不稳定。

7. 总结与下一步

恭喜！您已经成功搭建了一套 2026 年标准的家庭 All-in-One 网络中心。

🎉 您现在拥有了：

  • 高性能主路由 (iKuai 流控)

  • 全能旁路由 (OpenWrt 插件生态)

  • 私有云服务器 (Docker 运行各种服务)

  • 低功耗运行 (整机待机通常 < 15W)

📚 进阶推荐

  • 尝试直通 (Passthrough)：将网卡或 NVMe 硬盘直通给特定虚拟机，提升性能。
  • 外网访问：配置 ZeroTier 或 Tailscale，实现随时随地安全访问家中网络。
  • IPv6 部署：在 iKuai 中开启 IPv6 原生支持，体验更快的网络连接。

最后提醒：技术折腾无止境，但数据安全第一。请务必养成定期备份配置的习惯！
