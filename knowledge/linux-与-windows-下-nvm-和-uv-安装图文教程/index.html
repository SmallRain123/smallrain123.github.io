Linux 与 Windows 下 nvm 和 uv 安装图文教程

← 返回知识库

开发环境#知识库#开发环境#Linux

本教程详细介绍如何在 Linux 和 Windows 两大操作系统下安装 nvm（Node.js 版本管理器）和 uv（极速 Python 包管理器），并配有操作示意图，帮助开发者快速搭建多版本开发环境。

nvm 用于管理多个 Node.js 版本，uv 用于管理 Python 版本和依赖，两者搭配可覆盖前端与 Python 全栈开发需求。

工具简介

nvm 是什么

nvm（Node Version Manager）是一款 Node.js 版本管理工具，允许你在同一台机器上安装和切换多个 Node.js 版本，无需反复卸载重装。官方 nvm 原生支持 Linux 和 macOS，Windows 平台需使用社区移植版 nvm-windows。

uv 是什么

uv 是由 Astral 公司用 Rust 编写的极速 Python 包管理器和项目管理工具，安装速度比传统 pip 快 10-100 倍，同时支持 Python 版本管理、虚拟环境创建和依赖解析。uv 是单文件二进制，无需预先安装 Python 即可使用。

Linux 系统安装

以下步骤适用于 Ubuntu、Debian、CentOS、Fedora 等主流 Linux 发行版，以及 WSL（Windows Subsystem for Linux）环境。

安装 nvm

步骤一：执行安装脚本

打开终端，执行以下命令下载并运行 nvm 官方安装脚本：

curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash

如果系统没有 curl，可使用 wget 替代：

wget -qO- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash

步骤二：刷新环境变量

安装脚本会自动将 nvm 配置写入 ~/.bashrc（或 ~/.zshrc）。执行以下命令使配置立即生效，或直接关闭并重新打开终端：

source ~/.bashrc

步骤三：验证安装

nvm --version

输出版本号（如 0.40.1）即表示安装成功。

步骤四：安装并使用 Node.js

nvm install --lts
nvm use --lts
node -v
npm -v
如果在国内网络环境下下载 Node.js 速度较慢，可设置 nvm 镜像源：`export NVM_NODEJS_ORG_MIRROR=https://npmmirror.com/mirrors/node`

安装 uv

步骤一：执行安装脚本

在终端执行以下命令，uv 官方安装脚本会自动下载对应平台的二进制文件：

curl -LsSf https://astral.sh/uv/install.sh | sh

步骤二：刷新环境变量

uv 默认安装到 ~/.local/bin/，安装脚本会自动将该路径加入 shell 配置。执行以下命令使其生效：

source ~/.bashrc

步骤三：验证安装

uv --version

步骤四：安装 Python 并创建项目

uv python install 3.12
uv init my-project
cd my-project
uv add requests
uv run main.py

Windows 系统安装

Windows 原生不支持官方 nvm，需使用社区维护的 **nvm-windows**。uv 则提供了官方 PowerShell 安装脚本，原生支持 Windows。

安装 nvm（nvm-windows）

步骤一：卸载已有 Node.js（重要）

安装 nvm-windows 前，必须先卸载系统中已安装的 Node.js，否则会产生版本冲突。前往「设置 → 应用 → 已安装的应用」，搜索 Node.js 并卸载。

步骤二：下载安装包

访问 nvm-windows 官方发布页，下载最新版本的 nvm-setup.exe：

nvm-windows GitHub Releases

步骤三：运行安装向导

双击下载的 nvm-setup.exe，按照安装向导提示完成安装：

  1. 接受许可协议，点击 Next
  2. 选择 nvm 安装目录（默认 C:\Users\<用户名>\AppData\Roaming\nvm）
  3. 选择 Node.js 符号链接目录（默认 C:\Program Files\nodejs）
  4. 点击 Install 完成安装

步骤四：验证安装

打开新的 PowerShell 或命令提示符窗口，执行：

nvm version

步骤五：安装并使用 Node.js

nvm install lts
nvm use lts
node -v
npm -v
在 Windows 上执行 `nvm use` 需要管理员权限。请以「管理员身份运行」PowerShell 或 CMD，否则会提示权限不足。

安装 uv

步骤一：执行 PowerShell 安装命令

打开 PowerShell（无需管理员权限），执行以下命令：

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

步骤二：刷新环境变量

安装脚本会自动将 uv 路径加入用户环境变量。关闭当前 PowerShell 窗口，重新打开一个新窗口使环境变量生效。

步骤三：验证安装

uv --version

步骤四：安装 Python 并创建项目

uv python install 3.12
uv init my-project
cd my-project
uv add requests
uv run main.py

常用命令速查

nvm 常用命令

命令 说明
nvm install --lts 安装最新 LTS 版 Node.js
nvm install 20.10.0 安装指定版本 Node.js
nvm use --lts 切换到最新 LTS 版
nvm ls 列出已安装的所有版本
nvm ls-remote 列出所有可安装的远程版本（Linux/macOS）
nvm alias default 20 设置默认 Node.js 版本
nvm uninstall 18.0.0 卸载指定版本

uv 常用命令

命令 说明
uv python install 3.12 安装指定版本 Python
uv python list 列出已安装和可安装的 Python 版本
uv init my-project 初始化新项目
uv add requests 添加依赖包
uv remove requests 移除依赖包
uv sync 同步安装项目所有依赖
uv run main.py 在项目虚拟环境中运行脚本
uv pip install flask 兼容 pip 语法安装包

常见问题

nvm 命令找不到

Linux/macOS：确认 ~/.bashrc 或 ~/.zshrc 中包含 nvm 初始化代码，并执行 source 刷新。Windows：确认环境变量中包含 nvm 安装路径，重启终端后重试。

Windows 上 nvm use 报错

必须以管理员身份运行 PowerShell 或 CMD，因为 nvm use 需要创建符号链接，这需要管理员权限。

uv 安装后命令找不到

Linux：确认 ~/.local/bin 在 PATH 中。Windows：关闭并重新打开终端窗口，使环境变量生效。

国内下载速度慢

nvm 设置 Node.js 镜像：export NVM_NODEJS_ORG_MIRROR=https://npmmirror.com/mirrors/node（Linux）或 nvm node_mirror https://npmmirror.com/mirrors/node/（Windows）。uv 设置 PyPI 镜像：在项目中执行 uv config set index-url https://pypi.tuna.tsinghua.edu.cn/simple。
