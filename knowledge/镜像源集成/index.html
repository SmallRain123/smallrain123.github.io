Q1、APT 软件源（Ubuntu）

替换为国内镜像源（以阿里云为例）：

  1. 备份原有源：
sudo cp /etc/apt/sources.list{,.bak}
  1. 编辑源文件：
sudo nano /etc/apt/sources.list
  1. 替换为对应 Ubuntu 版本的阿里云源（例如 Ubuntu 22.04）：
deb http://mirrors.aliyun.com/ubuntu/ jammy main restricted universe multiverse
deb-src http://mirrors.aliyun.com/ubuntu/ jammy main restricted universe multiverse
deb http://mirrors.aliyun.com/ubuntu/ jammy-security main restricted universe multiverse
deb-src http://mirrors.aliyun.com/ubuntu/ jammy-security main restricted universe multiverse
deb http://mirrors.aliyun.com/ubuntu/ jammy-updates main restricted universe multiverse
deb-src http://mirrors.aliyun.com/ubuntu/ jammy-updates main restricted universe multiverse
deb http://mirrors.aliyun.com/ubuntu/ jammy-backports main restricted universe multiverse
deb-src http://mirrors.aliyun.com/ubuntu/ jammy-backports main restricted universe multiverse

其他版本替换jammy为对应代号（20.04 是focal，18.04 是bionic）

  1. 更新源：
sudo apt update

Q2、Docker 镜像加速

配置国内镜像源（阿里云 / 网易等）：

  1. 创建配置文件：
sudo mkdir -p /etc/docker
sudo nano /etc/docker/daemon.json
  1. 添加镜像源（可多选）：
{
    "registry-mirrors": 
    [
    "https://docker.mirrors.ustc.edu.cn",
    "https://hub-mirror.c.163.com",
    "https://reg-mirror.qiniu.com",
    "https://cr.console.aliyun.com/"  # 阿里云需登录控制台获取个人加速地址
    ]
}
  1. 重启 Docker 服务：
sudo systemctl daemon-reload
sudo systemctl restart docker

Q3、npm 镜像源

使用淘宝镜像（npmmirror）：

  1. 临时使用：
npm install --registry=https://registry.npmmirror.com
  1. 永久设置：
npm config set registry https://registry.npmmirror.com
  1. 验证设置：
npm config get registry  # 应输出https://registry.npmmirror.com
  1. 恢复默认（官方源）：
npm config set registry https://registry.npmjs.org

Q4、Conda 镜像源

配置 Anaconda 国内镜像（以清华大学为例）：

  1. 创建 / 编辑配置文件：
nano ~/.condarc
  1. 添加以下内容：
channels:- defaults
show_channel_urls: truedefault_channels:- https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main
  - https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/r
  - https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/msys2
custom_channels:conda-forge: https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud
  msys2: https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud
  bioconda: https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud
  menpo: https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud
  pytorch: https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud
  pytorch-lts: https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud
  simpleitk: https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud
  1. 清除缓存：
conda clean -i

Q5、pip 镜像源

配置国内 pip 镜像（以阿里云为例）：

  1. 临时使用：
pip install <包名> -i https://mirrors.aliyun.com/pypi/simple/
  1. 永久设置（推荐）：
# 创建配置目录
mkdir -p ~/.pip
# 编辑配置文件
vim ~/.pip/pip.conf
# 添加以下内容
[global]index-url = https://mirrors.aliyun.com/pypi/simple/[install]trusted-host = mirrors.aliyun.com

# 然后按:wq!保存退出

其他可选镜像源：

  • 清华大学：https://pypi.tuna.tsinghua.edu.cn/simple/
  • 豆瓣：https://pypi.doubanio.com/simple/
  • 中科大：https://pypi.mirrors.ustc.edu.cn/simple/

配置完成后，各类工具的下载速度会显著提升。如果某一镜像源不稳定，可切换到其他镜像源。
