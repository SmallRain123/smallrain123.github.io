Hermes Agent入门到实战

← 返回知识库

AI / 工具#知识库#AI / 工具#Hermes
为帮助开发者快速上手、落地实践，本文聚焦**Hermes Agent 环境部署与实战全流程**，从基础依赖安装、源码拉取、虚拟环境配置，到后续运行调试、功能扩展，提供清晰、可直接复现的操作步骤。内容以 Linux（Ubuntu 20.04 及以上）为基准环境，覆盖 git、uv、nvm 等关键工具，兼顾新手友好性与工程规范性，助力你快速搭建起稳定可用的 Hermes Agent 运行环境，开启自主智能体的开发与应用之旅。

环境准备

  • linux操作系统（Ubuntu 20.04或以上版本）
  • git工具
  • uv虚拟环境（python环境）
  • nvm工具（nodejs管理器）

一、环境部署

安装uv环境

curl -L --progress-bar https://astral.sh/uv/install.sh | sh

拉取github仓库源码

git clone https://github.com/NousResearch/hermes-agent ~/.local/hermes-agent

创建python虚拟环境

cd ~/.local/hermes-agent
uv venv

安装python 3.11

uv python install 3.11

安装pip依赖环境

uv run pip install -e .

二、Hermes agent配置

运行hermes

uv run hermes setup

选择 Quick setup

选择供应商

请根据自己的实际来配置，我选择的是国内的Minimax

输入token秘钥

注意这里用的是隐藏的直接粘贴即可

回车默认

选择模型

选择跳过

后面再配置技能

这里默认选y

测试

如果测试的情况下出现以下情况，可以检查下配置文件

可以输入/exit退出即可

创建hermes目录并且配置

## 在家目录创建hermes目录以及相关的目录
mkdir -p ~/.hermes/{cron,sessions,logs,memories,skills,plugins}

## 复制配置文件到 ~/.hermes文件夹下
cp -r cli-config.yaml.example ~/.hermes/config.yaml

## 创建一个.env文件,用来做环境变量
touch ~/.hermes/.env

## 写入文件
echo "MINIMAX_CN_API_KEY=你复制的API密钥" >> ~/.hermes/.env
echo "MINIMAX_CN_BASE_URL=https://api.minimax.com/anthropic" >> ~/.hermes/.env

## 执行文件
source ~/.hermes/.env

## 重新运行hermes
uv run hermes

三、webui配置

安装nvm工具

## 使用国内加速安装
curl -o- https://gitee.com/mirrors/nvm/raw/v0.39.7/install.sh | bash

## 执行文件
source ~/.bashrc

## 查看版本信息
nvm --version

安装node并且配置

## 安装25版本
nvm install 25

## 切换到25版本
nvm use 25

# 查看版本
node -v
npm -v

安装依赖

cd ~/.local/hermes-gent/web
npm install

执行构建

npm run build

启动测试

cd ~/.local/hermes-agent/

## 安装模块
uv pip install fastapi uvicorn

## 启动测试
uv run hermes dashbord

四、服务配置

## 在家目录下创建文件夹
mkdir -p ~/.config/systemd/user

## 配置hermes-gateway服务
vim ~/.config/systemd/user/hermes-gateway.service
## 复制粘贴一下内容：
[Unit]
Description=Hermes Gateway
After=network.target

[Service]
WorkingDirectory=%h/.local/hermes-agent
ExecStart=%h/.local/bin/uv run hermes gateway
Restart=always
RestartSec=3

[Install]
WantedBy=default.target
## 然后按esc输入:wq 保存退出

## 配置hermes-webui服务
vim ~/.config/systemd/user/hermes-webui.service
## 复制粘贴一下内容：
[Unit]
Description=Hermes WebUI Dashboard (uv, user service)
After=network.target

[Service]
Type=simple
WorkingDirectory=%h/.local/hermes-agent
ExecStart=%h/.local/bin/uv run hermes dashboard --tui --insecure --host 0.0.0.0 --port 9119
Restart=always
RestartSec=3
StartLimitInterval=60
StartLimitBurst=5
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=default.target
## 然后按esc输入:wq 保存退出

## 重载服务
systemctl --user daemon-reload

## 启动服务
systemctl --user start hermes-webui hermes-gateway

## 查看服务状态
systemctl --user status -l --no-pager hermes-gateway hermes-webui 

## 查看hermes启动端口
ss -tulnp |grep hermes

配置以上服务后就可以在别的电脑上访问了，在浏览器里输入http://IP:9117， IP部署到linux里的ip地址
