开发环境#知识库#开发环境#Ubuntu

一、安装 Node.js 的三种方式

方式 1：使用 nvm（推荐，多版本管理）

nvm（Node Version Manager）是管理多个 Node.js 版本的工具，灵活且适合开发环境。

  1. 安装 nvm
    执行官方安装脚本（确保已安装curl或wget）：
# 用curl安装
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash# 或用wget安装wget -qO- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
  1. 生效 nvm 配置
    关闭当前终端重开，或执行：
source ~/.bashrc  # 若用zsh则替换为 ~/.zshrc

  1. 安装 Node.js

    • 查看可用版本：nvm ls-remote
    • 安装最新 LTS 版本（推荐生产环境）：
    nvm install --lts
    • 安装指定版本（如 v18.18.0）：
    nvm install 18.18.0

  2. 切换 / 设置默认版本

nvm use 18.18.0       # 临时切换到18.18.0版本
nvm alias default 18  # 设置v18为默认版本

方式 2：通过 NodeSource 仓库（固定版本）

适合需要特定版本且不需要多版本切换的场景。

  1. 添加 NodeSource 源
    以 LTS 版本 18 为例（支持 20.04+）：
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
  1. 安装 Node.js
sudo apt-get install -y nodejs

方式 3：Ubuntu 默认仓库（版本较旧）

适合快速测试，版本可能不是最新：

sudo apt update
sudo apt install -y nodejs npm

二、验证安装

安装后检查版本：

node -v   # 输出Node.js版本（如v18.18.0）npm -v    # 输出npm版本（Node.js自带的包管理器）

三、更新与卸载

  • 更新 Node.js（nvm 方式）
nvm install --lts --reinstall-packages-from=current  # 安装最新LTS并迁移全局包
  • 更新 npm
npm install -g npm  # 更新到最新版
  • 卸载 Node.js
  • nvm 方式：nvm uninstall 18.18.0
  • NodeSource / 系统仓库：sudo apt remove --purge nodejs npm

四、常见问题解决

  • 权限错误（EACCES）：避免用sudo安装本地包，或配置 npm 全局目录：
mkdir ~/.npm-global
npm config set prefix '~/.npm-global'echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.bashrc
source ~/.bashrc
  • npm 镜像加速：切换国内镜像（如淘宝）：
npm config set registry https://registry.npmmirror.com

通过以上步骤，你可以在 Ubuntu 上轻松搭建 Node.js 开发环境，并进行项目开发和管理。根据需求选择合适的安装方式（nvm 更推荐开发场景）。
