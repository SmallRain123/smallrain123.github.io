NetworkManager安装及配置

← 返回知识库

Linux / 系统#知识库#Linux / 系统

一、安装

## 更新软件包
apt update && apt upgrade -y

## 安装network-manager
apt install -y network-manager

二、配置

2.1 文件配置

sudo tee /etc/netplan/00-installer-config.yaml << EOF
network:
    version: 2 
    renderer: NetworkManager
EOF

2.2 服务配置

# 先检查配置文件语法是否正确（推荐先检查，避免报错）
sudo netplan try

# 确认无误后，应用配置

sudo netplan apply

## 加载配置文件
sudo systemctl reload Network-Manager

## 设置服务开机自启
sudo systemctl enable Network-Manager

## 重启服务
sudo systemctl restart Network-Manager

2.3 网卡配置

1、dhcp自动获取

nmcli connection add type ethernet con-name ens18 ifname ens18 ipv4.method auto

2、静态ip地址配置

nmcli connection add type ethernet con-name ens18 ifname ens18 \
ipv4.method manual \
ipv4.addresses 192.168.0.100/24 \
ipv4.gateway 192.168.0.1 \
ipv4.dns 114.114.114.114

3、参数

4、网卡激活与关闭

# 查看状态
nmcli connection show

# 查看所有网卡信息
nmcli device show

# 或者查看指定网卡信息
nmcli device show ens18

# 激活网卡
nmcli connection up ens18

# 关闭网卡
nmcli connection down ens18
