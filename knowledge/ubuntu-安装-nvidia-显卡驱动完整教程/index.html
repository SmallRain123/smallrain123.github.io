Ubuntu 安装 NVIDIA 显卡驱动完整教程

← 返回知识库

GPU / 驱动#知识库#GPU / 驱动#Ubuntu#NVIDIA

适用系统: Ubuntu 20.04 / 22.04 / 24.04 LTS

适用显卡: NVIDIA GeForce / Quadro / Tesla / RTX 系列

最后更新: 2026-03-20

难度: ⭐⭐ 初级/中级

安装前检查

1.1 检查显卡硬件

# 查看 NVIDIA 显卡是否被系统识别
lspci | grep -i nvidia

预期输出示例：

01:00.0 VGA compatible controller: NVIDIA Corporation GA102 [GeForce RTX 3080] (rev a1)

⚠️ 如果没有输出，请检查：

  • 显卡是否正确插入 PCIe 插槽
  • 显卡供电线是否连接
  • BIOS 中是否禁用了独立显卡

1.2 检查 Secure Boot（重要！）

NVIDIA 专有驱动需要加载内核模块，如果 Secure Boot 启用，驱动将无法加载。

检查方法：

mokutil --sb-state

如果显示 SecureBoot enabled，需要禁用：

  1. 重启电脑，进入 BIOS/UEFI（按 F2/F12/Del 键）
  2. 找到 Secure Boot 选项
  3. 设置为 Disabled
  4. 保存并退出

1.3 查看当前驱动状态

# 查看已安装的 NVIDIA 驱动
nvidia-smi

# 查看当前使用的驱动
lsmod | grep nvidia

如果 nvidia-smi 报错，说明驱动未安装或有问题，可以继续本教程。

1.4 更新系统

sudo apt update
sudo apt upgrade -y
sudo reboot

方法一：使用 ubuntu-drivers（强烈推荐）⭐

这是最简单、最安全的方法，适合 95% 的用户。

步骤 1：查看可用驱动版本

ubuntu-drivers devices

输出示例：

== /sys/devices/pci0000:00/0000:00:01.0/0000:01:00.0 ==
modalias : pci:v000010DEd00002487sv00001458sd0000407Bbc03sc00i00
vendor   : NVIDIA Corporation
model    : GA102 [GeForce RTX 3080]
driver   : nvidia-driver-535 - distro non-free recommended
driver   : nvidia-driver-525 - distro non-free
driver   : nvidia-driver-470 - distro non-free

步骤 2：安装推荐驱动

# 自动安装推荐版本（最简单）
sudo ubuntu-drivers autoinstall

或手动指定版本：

# 安装特定版本（如 535）
sudo apt install -y nvidia-driver-535

步骤 3：安装额外组件（可选）

# NVIDIA 设置工具
sudo apt install -y nvidia-settings

# CUDA 开发工具（如需深度学习开发）
sudo apt install -y nvidia-cuda-toolkit

步骤 4：重启系统

sudo reboot

步骤 5：验证安装

nvidia-smi

方法二：使用附加驱动 GUI

适合不喜欢命令行的用户。

步骤 1：打开”软件和更新”

software-properties-gtk

或在应用菜单中搜索 “软件和更新” (Software & Updates)。

步骤 2：切换到”附加驱动”标签

  1. 点击 “附加驱动” (Additional Drivers) 标签
  2. 等待系统搜索可用驱动（可能需要 1-2 分钟）

步骤 3：选择驱动

  • 选择标记为 (recommended) 或 (proprietary, tested) 的版本
  • 新显卡（RTX 30/40 系列）: 选择 535 或更高
  • 旧显卡（GTX 10 系列）: 选择 470 或 525

步骤 4：应用并重启

  1. 点击 “应用更改” (Apply Changes)
  2. 等待安装完成（5-10 分钟）
  3. 重启系统

方法三：手动安装官方.run 文件

⚠️ 警告: 此方法风险较高，仅在前两种方法失败时使用。

适用场景: 需要最新驱动版本、特殊显卡、或仓库驱动不兼容

步骤 1：下载官方驱动

访问 NVIDIA 驱动下载页面

或使用命令行下载（以 550 版本为例）：

cd ~/Downloads
wget https://us.download.nvidia.com/XFree86/Linux-x86_64/550.54.14/NVIDIA-Linux-x86_64-550.54.14.run

步骤 2：禁用 Nouveau 开源驱动

# 创建黑名单文件
sudo tee /etc/modprobe.d/blacklist-nouveau.conf << EOF
blacklist nouveau
blacklist lbm-nouveau
options nouveau modeset=0
EOF

# 更新 initramfs
sudo update-initramfs -u

# 重启
sudo reboot

步骤 3：验证 Nouveau 已禁用

lsmod | grep nouveau

无输出 表示禁用成功。

步骤 4：停止图形界面

重启后，在登录界面按 Ctrl+Alt+F3 进入 TTY 终端，登录后执行：

# 停止显示管理器
sudo systemctl stop gdm3    # GNOME (Ubuntu 默认)
# 或
sudo systemctl stop lightdm # LightDM
# 或
sudo systemctl stop sddm    # KDE

步骤 5：安装驱动

cd ~/Downloads
chmod +x NVIDIA-Linux-x86_64-*.run

# 安装（关键参数）
sudo ./NVIDIA-Linux-x86_64-*.run --no-opengl-files

安装选项建议：

  • 是否注册内核模块源：Yes
  • 是否安装 32 位兼容库：根据需要
  • 是否运行 nvidia-xconfig: Yes

步骤 6：重启系统

sudo reboot

验证安装

检查驱动状态

nvidia-smi

成功输出示例：

检查 OpenGL

glxinfo | grep "OpenGL version"

应显示 OpenGL version string: 4.6.0 NVIDIA ...

检查内核模块

lsmod | grep nvidia

应看到 nvidia, nvidia_uvm, nvidia_drm 等模块。

测试渲染

glxgears

应看到旋转的齿轮动画，终端显示 FPS。

常见问题解决

❌ 问题 1: nvidia-smi 报错 “NVIDIA-SMI has failed”

可能原因：

  • Secure Boot 未禁用
  • 内核模块未加载
  • 驱动版本与内核不兼容

解决方案：

# 1. 检查 Secure Boot
mokutil --sb-state

# 2. 手动加载模块
sudo modprobe nvidia
sudo modprobe nvidia-uvm

# 3. 查看错误日志
dmesg | grep NVRM

# 4. 重新安装驱动
sudo apt purge -y nvidia-*
sudo ubuntu-drivers autoinstall
sudo reboot

❌ 问题 2: 重启后黑屏或登录循环

解决方案：

  1. 进入 TTY (Ctrl+Alt+F3)

  2. 卸载驱动：

    sudo apt purge -y nvidia-*
sudo reboot

  3. 重新安装时选择更低版本驱动

  4. 或检查是否安装了冲突的 OpenGL 文件

❌ 问题 3: Wayland 会话下驱动异常

解决方案：

  1. 在登录界面选择 Ubuntu on Xorg

  2. 或编辑 /etc/gdm3/custom.conf：取消注释：WaylandEnable=false

    sudo nano /etc/gdm3/custom.conf

❌ 问题 4: 内核升级后驱动失效

解决方案：

# 重新安装驱动
sudo ubuntu-drivers autoinstall

# 或手动重建内核模块
sudo dkms autoinstall
sudo reboot

❌ 问题 5: 风扇全速或温度过高

解决方案：

# 安装 nvidia-settings
sudo apt install nvidia-settings

# 运行设置工具
nvidia-settings

# 启用持久模式
sudo nvidia-persistenced

卸载驱动

使用 apt 卸载

# 卸载所有 NVIDIA 驱动
sudo apt purge -y nvidia-*
sudo apt autoremove -y
sudo reboot

恢复 Nouveau 驱动

# 删除黑名单文件
sudo rm /etc/modprobe.d/blacklist-nouveau.conf

# 更新 initramfs
sudo update-initramfs -u

# 重启
sudo reboot

📊 驱动版本选择指南

显卡系列 推荐驱动版本 备注
RTX 40 系列 535-550+ 必须使用 535 或更高
RTX 30 系列 525-535 525 稳定，535 新功能
RTX 20 系列 525-535 同上
GTX 16 系列 525-535 同上
GTX 10 系列 470-525 470 最稳定
GTX 9 系列及更早 470 仅支持到 470
Tesla/数据中心 根据 CUDA 需求 参考 NVIDIA 官方文档
