LongCat 是 Claude Opus 4.6 模型的一个代号，这是目前最先进的 Claude 模型，特别适合复杂的软件开发任务。

配置 LongCat 模型

设置默认模型

# 将 LongCat (Claude Opus 4.6) 设为默认模型
claude config set model claude-opus-4-6

# 验证配置
claude config list

临时使用 LongCat

# 在特定会话中使用 LongCat
claude --model claude-opus-4-6

# 或者在对话中指定
claude --model longcat-flash-chat

实际案例演示

案例 1：构建高性能 API

用户：使用 FastAPI 构建一个高性能的用户管理 API，要求支持 1000+ QPS
LongCat：让我为你设计一个高性能的 FastAPI 应用...

from fastapi import FastAPI, Depends, HTTPException
from sqlalchemy.orm import Session
from redis import Redis
import asyncio
from typing import List

app = FastAPI()

# Redis 缓存
redis_client = Redis(host='localhost', port=6379, db=0)

@app.get("/users/{user_id}")
async def get_user(user_id: int, db: Session = Depends(get_db)):
    # 先查缓存
    cache_key = f"user:{user_id}"
    cached_user = redis_client.get(cache_key)

    if cached_user:
        return {"user": cached_user, "from_cache": True}

    # 缓存未命中，查数据库
    user = await db.query(User).filter(User.id == user_id).first()
    if not user:
        raise HTTPException(status_code=404, detail="User not found")

    # 设置缓存
    redis_client.setex(cache_key, 300, user.json())  # 5分钟过期

    return {"user": user, "from_cache": False}

@app.get("/users/")
async def get_users(
    skip: int = 0,
    limit: int = 100,
    db: Session = Depends(get_db)
):
    # 使用分页和连接池优化
    users = await db.query(User).offset(skip).limit(limit).all()
    return users

        df = self.spark.read.parquet(f"s3://data-lake/user-behavior/{date_range}")

        # 用户行为分析
        result = df.groupBy("user_id", "event_type") \
                   .agg({
                       "timestamp": "count",
                       "duration": "avg"
                   }) \

                   .withColumnRenamed("avg(duration)", "avg_duration")

        return result
