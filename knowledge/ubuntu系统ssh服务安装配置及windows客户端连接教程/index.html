Ubuntu系统SSH服务安装配置及Windows客户端连接教程

← 返回知识库

Linux / 系统#知识库#Linux / 系统#Ubuntu#Linux

本教程适用于所有主流Ubuntu版本（18.04/20.04/22.04/24.04），完整讲解Ubuntu服务端SSH部署、参数配置、开机自启、防火墙放行，以及Windows原生终端、第三方工具远程连接方法，附带常见故障排查，零基础可直接照着操作。

内容概览

  • 第一部分 · 服务端配置：6 步完成 SSH 安装与配置（更新源 → 安装 → 状态验证 → 防火墙放行 → 配置优化 → 查询本机 IP）
  • 第二部分 · 客户端连接：Windows 原生终端、Xshell 两种连接方式
  • 第三部分 · 关键注意事项：网络互通、账号密码、端口、安全建议
  • 第四部分 · 故障排查：4 种常见连接问题及解决方法

一、Ubuntu服务端配置SSH服务

1. 更新系统软件源（可选推荐）

先更新软件包列表，避免安装报错，打开Ubuntu终端（Ctrl+Alt+T）执行命令：

sudo apt update && sudo apt upgrade -y

2. 安装OpenSSH服务端

Ubuntu默认未预装SSH服务，需手动安装openssh-server组件：

sudo apt install openssh-server -y

3. 查看SSH服务状态

安装完成后服务会自动启动，执行以下命令验证运行状态：

systemctl status ssh

出现 active (running) 即为运行正常。

常用服务控制命令：

# 启动SSH服务
sudo systemctl start ssh
# 停止SSH服务
sudo systemctl stop ssh
# 重启SSH服务（修改配置后必执行）
sudo systemctl restart ssh
# 设置开机自启（核心配置，避免重启失效）
sudo systemctl enable ssh

4. 放行Ubuntu防火墙SSH端口

Ubuntu默认防火墙UFW开启后会拦截SSH连接，需手动放行22端口（SSH默认端口）：

# 放行SSH服务
sudo ufw allow ssh
# 或直接放行22端口（效果一致）
sudo ufw allow 22/tcp
# 重载防火墙生效
sudo ufw reload
# 查看防火墙规则
sudo ufw status

5. SSH核心配置优化（可选，推荐）

修改SSH配置文件，提升安全性、解决连接限制问题：

sudo vim /etc/ssh/sshd_config

打开文件后，修改/确保以下参数（去掉行首#注释，无则新增）：

# 允许密码登录（新手开启，生产环境建议改用密钥登录）
PasswordAuthentication yes
# 允许root登录（按需开启，普通用户可关闭）
PermitRootLogin yes
# 开启端口转发
AllowTcpForwarding yes
# 最大连接数，避免连接超时
MaxSessions 10

修改完成后，重启SSH服务使配置生效：

sudo systemctl restart ssh

6. 查看Ubuntu本机IP（连接必备）

Windows连接需要Ubuntu的IP地址，执行命令查询：

ip a

找到网卡（一般为ens33、eth0、wlan0）对应的 inet 192.168.x.x 地址，记录该IP，后续连接使用。

二、Windows客户端连接Ubuntu SSH

提供两种常用连接方式，优先推荐Windows原生终端（无需装软件），新手友好。

方式一：Windows CMD/PowerShell 原生连接（Win10/Win11自带）

Win10 1809版本及以上、Win11默认内置SSH客户端，无需额外安装。

  1. 按下 Win+R，输入 cmd 或 powershell 打开终端；
  2. 输入连接命令，格式：ssh 用户名@UbuntuIP

示例（Ubuntu用户为ubuntu，IP为192.168.1.100）：

ssh ubuntu@192.168.1.100

首次连接提示Are you sure you want to continue connecting (yes/no)?，输入 yes 回车；

输入Ubuntu登录密码（输入时无显示，直接输完回车即可），连接成功。

方式二：Xshell客户端连接（第三方工具，适合长期使用）

Xshell支持会话保存、字体优化、文件传输，是运维常用工具。

  1. 下载安装Xshell（免费家庭版即可）；

  2. 打开软件，点击「文件」-「新建」，新建会话；

  3. 会话属性配置：

    • 协议：SSH
    • 主机：填写Ubuntu的IP地址
    • 端口号：22（默认无需修改）

  4. 点击「连接」，输入Ubuntu用户名和密码，即可登录；

  5. 可保存会话，下次打开直接双击连接，无需重复输入信息。

三、关键注意事项

- **网络互通**：Windows和Ubuntu必须在**同一局域网**（同一WiFi/同一交换机），否则无法连接；云服务器需放行安全组22端口。 - **账号密码**：登录时使用Ubuntu的普通用户名/root账号及对应密码，不是Windows账号密码。 - **端口问题**：默认SSH端口22，若手动修改配置文件端口，连接时需指定端口：`ssh -p 端口 用户名@IP`。 - **安全建议**：测试环境可开启密码登录，生产环境建议关闭密码登录，使用密钥登录提升安全性。

四、常见故障排查

1. 提示：Connection refused（连接被拒绝）

原因：Ubuntu SSH服务未启动、未安装、端口错误。

解决：重新执行 systemctl status ssh 检查服务状态，重启SSH服务，确认端口为22。

2. 提示：No route to host（无法连接主机）

原因：网络不通、防火墙未放行端口、IP地址错误。

解决：确认双方同一局域网，检查Ubuntu防火墙规则，重新核对IP地址。

3. 输入密码正确但登录失败

原因：配置文件关闭了密码登录、禁止当前用户登录。

解决：修改sshd_config文件，开启 PasswordAuthentication yes，重启SSH服务。

4. Win10旧版本无SSH命令

解决：设置-应用-可选功能-添加功能，搜索「OpenSSH客户端」安装即可。
