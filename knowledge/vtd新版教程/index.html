VTD新版教程

← 返回知识库

AI / 工具#知识库#AI / 工具#VTD

确认操作系统和显卡驱动

  • 系统推荐：Ubuntu 18.04
  • 显卡驱动：NVIDIA 版本需 ≥ 440.82

安装依赖

sudo apt-get install xterm freeglut3 openssh-server nfs-common mesa-utils xfonts-75dpi libusb-0.1-4 python mesa-common-dev libgl1-mesa-dev
sudo apt-get update

安装 VTD 软件

3.1 安装基本软件包

  1. 安装前确认硬盘空间：至少 30G
  2. 在home目录下创建VIRES文件夹
  3. 在安装包所在目录打开终端，执行命令：
./VTD.2020_Run.Perception.Installer.20200515.bin -i gui
  1. 安装界面一路next，安装目录需选择有读写权限的路径
  2. 安装完成后选择不添加 license 信息

3.2 安装 perception 附加软件包

在安装包所在目录打开终端，执行命令：

./VTD.2020_Dev.Perception.Installer.20200515.bin -i gui

出现界面后一路next完成安装

3.3 安装 ROD 附加软件包

将 ROD 压缩包解压至VTD.2020/Runtime/Tools目录

运行 VTD

在VTD.2020/bin目录打开终端，执行命令：

./vtdStart.sh

主界面启动后，上侧工具栏中间的勾为灰色，表示未激活

二、激活 VTD（安装 helium）

确认主机名和 MAC 地址

1.1 Ubuntu 账户格式

格式：A@B，示例：zhijiauto@zhijiauto-abcd123

1.2 查询 MAC 地址

终端执行命令：

ifconfig

eth0对应的地址即为 MAC 地址

安装依赖

2.1 安装 java 依赖

sudo apt install openjdk-8*

2.2 安装 lsb

sudo apt-get install lsb

更改 license 文件

3.1 安装 vim（未安装时执行）

sudo apt install vim

3.2 修改 license 第一行

格式：SERVER 主机名(B) MAC地址 27500 示例：SERVER zhijiauto-abcd123 XX:XX:XX:XX:XX:XX 27500

3.3 修改 license 第二行

  1. 在VIRES文件夹打开终端，创建目录：
mkdir MSCLicensing
mkdir MSCLicensing/LOG
  1. 修改第二行格式：DAEMON MSC /home/A/VIRES/MSCLicensing/Helium

安装 helium

法一（推荐）：Console 安装

./msc_licensing_helium_linux64.bin --mode console

后续操作：

  1. 输入Y确认
  2. 安装路径：/home/A/VIRES/MSCLicensing
  3. 日志路径：/home/A/VIRES/MSCLicensing/LOG
  4. 输入 license 的 dat 文件路径
  5. 按两次空格，依次输入Y、Y、N

验证进程：

# 进入Helium文件夹查看ls# 查看运行状态
./lmutil lmstat -c license.dat

修改启动脚本：

# 进入VTD bin目录vim vtdStart.sh

取消第 38 行注释，修改为：="27500@B"（保留双引号）

法二（不推荐）：GUI 安装

# 修改权限sudo chmod 777 msc_licensing_helium_linux64.bin
sudo chmod +x msc_licensing_helium_linux64.bin
# 启动安装
./msc_licensing_helium_linux64.bin

⚠️ 注意：默认路径需删除空格，否则无法二次启动；部分场景会出现卡顿

验证激活成功

在VTD.2020/bin目录执行：

./vtdStart.sh

工具栏中间的勾变为绿色，代表激活成功

三、其他设置

完成激活后，以下为无关激活的辅助配置：

License Server 单独控制

# 启动
./lmutil lmstat -c license.dat
# 显式启动
./lmgrd -c license.dat -l ../LOG/lmgrd.log
# 关闭
./lmutil lmdown -c license.dat

开机自启配置

  1. 查看Helium/startup_script/README
  2. 复制脚本：
cp msclmgrd.example /etc/init.d/msclmgrd
sudo chmod +x msclmgrd
  1. 查询启动级别：runlevel，在对应rcN.d创建软链接
  2. 验证：./lmutil lmstat -c license.dat

卸载 helium

./msc_licensing_helium_linux64.bin --mode console

选择Uninstall完成卸载

网卡设置

禁用无关网卡，避免 License Server 识别错误 MAC 地址

VTD 环境变量配置

修改VTD.2019.1/bin/vtdStart.sh，追加：

<EnvVar name="LM_LICENSE_FILE" val="27500@vtdmaster" />

终端临时配置：

export LM_LICENSE_FILE="[PORT]@[LICENSE-SERVER]"

分布式从机配置

在从机Process内添加环境变量：

<EnvVar name="LM_LICENSE_FILE" val="27500@vtdmaster" />

四、同一局域网下服务器连接（客户端获取 license）

服务器端安装并启动 SSH

# 安装服务端sudo apt-get install openssh-server
# 重启服务
/etc/init.d/ssh restart
# 验证运行状态netstat -tlp

出现tcp6 0 0 *:ssh : LISTEN -表示运行正常

客户端连接服务器

服务器账户格式：C@D 在客户端 bin 目录执行：

ssh C@D

客户端修改 vtdStart.sh

vim vtdStart.sh

取消第 38 行注释，修改为：="27500@D"（保留双引号）
