一、Miniconda 与 Anaconda 的区别

在安装之前，你可以根据下表快速了解两者的主要区别，以便选择更适合你的版本：

简要来说： 如果你不确定选哪个，或者希望节省磁盘空间和带宽，通常Miniconda是更好的选择，因为它允许你按需安装包。

二、✨ 安装步骤

这里以安装Miniconda为例（更通用和轻量），如果你想安装完整的Anaconda，只需替换下载链接和安装脚本名称即可28。

步骤 1: 更新系统包列表

首先打开终端（Terminal），确保你的系统软件包列表是最新的：

sudo apt update && sudo apt upgrade -y

同时，建议安装一些基础依赖：

sudo apt install wget curl -y

步骤 2: 下载 Miniconda 安装脚本

使用 wget 或 curl 下载最新的 Miniconda 安装脚本（Linux x86_64 版本）：

wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh

或者

curl -O https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh

步骤 3: 运行安装脚本

  1. 首先给下载的脚本添加执行权限：
chmod +x Miniconda3-latest-Linux-x86_64.sh
  1. 运行安装脚本并根据提示操作：
./Miniconda3-latest-Linux-x86_64.sh

安装过程中你会看到：

  • 按 Enter 键阅读许可协议。
  • 输入 yes 同意许可条款。
  • 确认安装路径（默认是 ~/miniconda3），一般直接按 Enter 使用默认路径即可。
  • 重要： 询问是否初始化 Conda 时，输入 yes。这会将 Conda 添加到你的 shell 配置文件中（通常是 ~/.bashrc），这是避免后续出现 conda: command not found 错误的关键258。

步骤 4: 激活安装

安装完成后，初始化命令会自动添加到你的 ~/.bashrc 文件中。你需要让当前终端重新加载这个配置文件才能立即生效：

source ~/.bashrc

如果你使用的是 Zsh shell，则需要运行：

source ~/.zshrc

或者直接新开一个终端窗口也可以。

步骤 5: 验证安装

激活后，你的命令行提示符前应该会出现一个 (base) 前缀，这表示你当前处于 Conda 的 base 环境中。
通过以下命令验证 Conda 是否安装成功并查看其版本：

conda --version

如果成功安装，则会输出类似 conda 24.7.2 的版本号2。

三、⚙️ 安装后配置与使用

基本 Conda 命令

安装成功后，你可以使用以下常用命令3：

配置国内镜像源（加速下载）

如果你在国内，可以通过配置清华源等国内镜像来大幅提升包的下载速度38：

conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/free/
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main/
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/conda-forge/
conda config --set show_channel_urls yes

禁用自动激活 base 环境（可选）

每次打开终端都自动进入 (base) 环境可能并不必要。你可以选择禁用它4：

conda config --set auto_activate_base false

之后需要手动激活 base 环境时，只需执行：

conda activate base

四、❌ 常见问题及解决方法

  • 问题：安装后输入 conda --version 提示 conda: command not found

    • **原因：**最可能的是安装时没有同意初始化（init），或者没有重新加载 shell 配置。

    • **解决：**1、首先重新加载 ~/.bashrc：source ~/.bashrc。2、如果还不行，可以手动初始化。请先确保你已经退出了 Conda 环境（如果提示符前有 (base)，先执行 conda deactivate），然后运行：3、之后再次执行 source ~/.bashrc58。

      # 请将 /path/to/your/ 替换为你的实际安装路径，通常是 ~/miniconda3 或 ~/anaconda3
source /path/to/your/miniconda3/bin/activate
conda init

  • 问题：如何彻底卸载 Conda？最后记得编辑 ~/.bashrc（或 ~/.zshrc）文件，删除所有与 Conda 初始化相关的代码块（通常是以 # >>> conda initialize >>> 开头和结尾的部分）。

    • 删除整个安装目录和配置文件即可
    rm -rf ~/miniconda3 # 如果你安装的是 Miniconda
rm -rf ~/anaconda3 # 如果你安装的是 Anaconda
rm -rf ~/.condarc ~/.conda ~/.continuum # 删除相关配置和缓存目录

五、💎 总结

在 Ubuntu 上安装 Conda 的流程可以概括为：更新系统 → 下载安装脚本 → 运行脚本并同意初始化 → 激活配置 → 验证安装。关键点是确保在安装过程中选择 yes 来进行初始化，这样就可以直接在命令行中使用 conda 命令了。

安装成功后，你就可以使用 Conda 来创建隔离的 Python 环境（例如为不同项目配置不同版本的 Python 和库），方便地安装、管理和卸载软件包，从而避免项目之间的依赖冲突，大大提高开发效率。
