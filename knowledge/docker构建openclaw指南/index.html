Docker构建OpenClaw指南

← 返回知识库

Docker / 容器#知识库#Docker / 容器#Docker#OpenClaw

本文档介绍如何使用Docker来构建和部署OpenClaw。

前提条件

  • 已安装Docker
  • 已安装Docker Compose（可选）
  • 基本的Linux命令行知识

快速开始

1. 克隆OpenClaw仓库

git clone https://github.com/openclaw/openclaw.git
cd openclaw

2.查看Dockfile文件

FROM  node:22-bookworm@sha256:cd7bcd2e7a1e6f72052feb023c7f6b722205d3fcab7bbcbd2d1bfdab10b1e935

# 安装 Bun (构建脚本所需)
RUN curl -fsSL https://bun.sh/install | bash
ENV PATH="/root/.bun/bin:${PATH}"

# 启用 corepack (用于管理包管理器)
RUN corepack enable

# 设置工作目录
WORKDIR /app
# 修改工作目录所有权为 node 用户
RUN chown node:node /app

# 构建参数：自定义需要安装的 APT 软件包
ARG OPENCLAW_DOCKER_APT_PACKAGES=""
# 如果指定了自定义软件包，则更新并安装
RUN if [ -n "$OPENCLAW_DOCKER_APT_PACKAGES" ]; then \
      apt-get update && \
      DEBIAN_FRONTEND=noninteractive apt-get install -y --no-install-recommends $OPENCLAW_DOCKER_APT_PACKAGES && \
      apt-get clean && \
      rm -rf /var/lib/apt/lists/* /var/cache/apt/archives/*; \
    fi

# 复制包管理相关文件，并设置正确的文件所有者
COPY --chown=node:node package.json pnpm-lock.yaml pnpm-workspace.yaml .npmrc ./
COPY --chown=node:node ui/package.json ./ui/package.json
COPY --chown=node:node patches ./patches
COPY --chown=node:node scripts ./scripts

# 切换到 node 非特权用户
USER node
# 降低低内存主机上依赖安装时的内存溢出(OOM)风险
# 小型虚拟机上的 Docker 构建可能会因内存不足而被"杀死"(退出码 137)
RUN NODE_OPTIONS=--max-old-space-size=2048 pnpm install --frozen-lockfile

# 可选：安装 Chromium 和 Xvfb 用于浏览器自动化
# 构建时启用：docker build --build-arg OPENCLAW_INSTALL_BROWSER=1 ...
# 会增加约300MB镜像体积，但避免了每次容器启动时60-90秒的 Playwright 安装过程
# 必须在 pnpm install 之后执行，确保 node_modules 中存在 playwright-core
USER root
ARG OPENCLAW_INSTALL_BROWSER=""
RUN if [ -n "$OPENCLAW_INSTALL_BROWSER" ]; then \
      apt-get update && \
      DEBIAN_FRONTEND=noninteractive apt-get install -y --no-install-recommends xvfb && \
      mkdir -p /home/node/.cache/ms-playwright && \
      PLAYWRIGHT_BROWSERS_PATH=/home/node/.cache/ms-playwright \
      node /app/node_modules/playwright-core/cli.js install --with-deps chromium && \
      chown -R node:node /home/node/.cache/ms-playwright && \
      apt-get clean && \
      rm -rf /var/lib/apt/lists/* /var/cache/apt/archives/*; \
    fi

# 切换回 node 用户
USER node
# 复制项目所有源代码
COPY --chown=node:node . .
# 执行项目构建
RUN pnpm build
# 强制使用 pnpm 构建 UI (Bun 在 ARM/群晖架构上可能失败)
ENV OPENCLAW_PREFER_PNPM=1
# 构建 UI 界面
RUN pnpm ui:build

# 设置生产环境
ENV NODE_ENV=production

# 安全加固：以非 root 用户运行
# node:22-bookworm 镜像内置了 'node' 用户 (uid 1000)
# 这通过防止 root 权限的容器逃逸来减少攻击面
USER node

# 使用默认配置启动网关服务器
# 默认绑定到回环地址(127.0.0.1)以提高安全性
#
# 对于需要外部健康检查的容器平台：
#   1. 设置 OPENCLAW_GATEWAY_TOKEN 或 OPENCLAW_GATEWAY_PASSWORD 环境变量
#   2. 覆盖 CMD 命令: ["node","openclaw.mjs","gateway","--allow-unconfigured","--bind","lan"]
CMD ["node", "openclaw.mjs", "gateway", "--allow-unconfigured"]

3. 构建Docker镜像

docker build -t openclaw:latest .

4. 运行OpenClaw容器

docker run -d \
  --name openclaw \
  -p 18789:18789 \
  -v $(pwd):/app/workspace \
  openclaw:latest

Docker Compose配置

创建docker-compose.yml文件：

version: '3.8'

services:
  openclaw:
    build: .
    ports:
      - "18789:18789"
    volumes:
      - ./workspace:/app/workspace
      - ./data:/app/data
    environment:
      - OPENCLAW_PORT=18789
      - OPENCLAW_MODEL=default
    restart: unless-stopped

构建服务并启动：

docker-compose up -d --build

常见问题

配置命令

docker ps -a |grep -i openclaw #查看openclaw是否正在运行
docker logs -f openclaw        #查看openclaw容器日志
docker logs exec -it openclaw node opecnclaw.mjs gateway status # 查看网关状态
docker logs exec -it openclaw node opecnclaw.mjs dashborad --install-daemon  # 配置openclaw

端口冲突

如果18789端口被占用，可以修改端口映射：

docker run -p 8080:18789 openclaw:latest

权限问题

确保工作目录有正确的读写权限：

chmod -R 755 /path/to/workspace

故障排除

  1. 查看容器日志：
docker logs openclaw
  1. 进入容器调试：
docker exec -it openclaw bash
  1. 检查容器状态：
docker ps -a
