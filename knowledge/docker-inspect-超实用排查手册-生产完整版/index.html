docker inspect 超实用排查手册（生产完整版）

← 返回知识库

Docker / 容器#知识库#Docker / 容器#Docker

docker inspect 是 Docker 排错最强命令，90% 容器异常：闪退、启动失败、端口冲突、挂载错误、自动退出、OOM、网络异常，都靠它定位根因。

默认输出 JSON 完整结构，生产中绝不建议裸跑无参数 inspect，必须用 –format 模板精准过滤。

一、基础语法

# 支持 容器名 / 容器ID / 镜像ID
docker inspect [容器/镜像]

# 精华用法：格式化输出（生产必备）
docker inspect --format '{{模板}}' 容器名

二、核心状态排查（容器闪退、退出、挂掉 首选）

重点：所有容器异常，第一步先看 State 状态

2.1 一键查看退出码、运行状态、OOM

docker inspect --format '
运行状态：{{.State.Status}}
是否运行：{{.State.Running}}
退出码：{{.State.ExitCode}}
是否OOM杀死：{{.State.OOMKilled}}
启动时间：{{.State.StartedAt}}
停止时间：{{.State.FinishedAt}}
错误信息：{{.State.Error}}
' 容器名

2.2 退出码黄金解读（生产 100% 够用）

  • ExitCode = 0：正常主动退出
  • ExitCode = 1：程序代码异常、配置错误、启动参数错误
  • ExitCode = 137：被系统强制 kill -9 / 内存溢出 OOM
  • ExitCode = 143：优雅终止 SIGTERM（被 docker stop/重启/脚本停掉）

三、容器启动配置排查（启动失败必查）

3.1 查看真正启动命令（最常用）

docker inspect --format '
入口程序：{{.Config.Entrypoint}}
启动参数：{{.Config.Cmd}}
工作目录：{{.Config.WorkingDir}}
' 容器名

3.2 查看环境变量

docker inspect --format '{{.Config.Env | json}}' 容器名

3.3 查看重启策略（解决容器不自动重启）

docker inspect --format '
重启策略：{{.HostConfig.RestartPolicy.Name}}
最大重试次数：{{.HostConfig.RestartPolicy.MaximumRetryCount}}
' 容器名

生产标准：always 宕机、重启、异常自动拉起

四、端口与网络排查（服务访问不通必查）

4.1 查看宿主机 & 容器端口映射

docker inspect --format '{{.HostConfig.PortBindings | json}}' 容器名

4.2 查看容器真实IP、网关、网络模式

docker inspect --format '
{{range $k,$v := .NetworkSettings.Networks}}
网络模式：{{$k}}
容器IP：{{$v.IPAddress}}
网关：{{$v.Gateway}}
{{end}}' 容器名

4.3 查看容器暴露端口

docker inspect --format '{{.Config.ExposedPorts | json}}' 容器名

五、挂载数据卷排查（数据丢失、配置不生效必查）

docker inspect --format '
{{range .Mounts}}
宿主机路径：{{.Source}}
容器内路径：{{.Destination}}
挂载类型：{{.Type}}
{{end}}' 容器名

核心结论：没有挂载 = 容器删除数据全部丢失

六、日志排查（定位报错源头）

6.1 获取容器真实日志文件路径

docker inspect --format '{{.LogPath}}' 容器名

可直接用 tail/less 查看原始日志，比 docker logs 更稳定

tail -f $(docker inspect --format '{{.LogPath}}' 容器名)

6.2 查看日志驱动 & 日志限制

docker inspect --format '{{.HostConfig.LogConfig | json}}' 容器名

七、资源限制排查（OOM、卡顿必查）

docker inspect --format '
内存限制：{{.HostConfig.Memory}}
CPU核心：{{.HostConfig.NanoCpus}}
PID数量限制：{{.HostConfig.PidsLimit}}
' 容器名

八、生产最强一键排查命令（全套信息）

复制直接用，一个命令输出所有排错关键信息

docker inspect --format '
==========容器基础信息==========
容器ID：{{.Id}}
容器名：{{.Name}}
创建时间：{{.Created}}

==========运行状态==========
运行状态：{{.State.Status}}
是否运行：{{.State.Running}}
退出码：{{.State.ExitCode}}
OOM杀死：{{.State.OOMKilled}}
启动时间：{{.State.StartedAt}}
停止时间：{{.State.FinishedAt}}

==========启动配置==========
启动入口：{{.Config.Entrypoint}}
启动参数：{{.Config.Cmd}}
工作目录：{{.Config.WorkingDir}}
重启策略：{{.HostConfig.RestartPolicy.Name}}

==========网络端口==========
端口映射：{{.HostConfig.PortBindings | json}}

==========日志路径==========
日志文件：{{.LogPath}}
' 容器名

九、inspect 结合排错完整流程（标准流水线）

容器异常 = 固定排查顺序

  1. inspect 查看 ExitCode、OOM 状态（定位大类问题）
  2. 查看日志，确认崩溃前报错详情
  3. 检查启动命令是否正确、参数是否缺失
  4. 检查端口冲突、监听地址、网络
  5. 检查挂载是否生效、配置文件是否持久化
  6. 检查资源限制（内存/CPU）
  7. 检查重启策略，防止意外停止不拉起

十、常见问题速查

1. 容器运行一会儿自动停？

inspect 看 ExitCode=143 → 外部停止，设置 always 重启策略

2. 容器启动瞬间闪退？

inspect 看 ExitCode=1 → 程序配置/启动命令错误，看启动参数 + 日志

3. 容器莫名被杀死？

inspect 看 OOMKilled=true / ExitCode=137 → 内存溢出

4. 修改配置不生效？

inspect 看 Mounts，检查挂载是否正确覆盖

5. 外网访问不通？

inspect 看 PortBindings + 容器监听 IP 是否为 0.0.0.0

十一、inspect 高阶技巧

1. json 格式化输出（万能解析）

# 任意字段直接json格式化，排版超级舒服
docker inspect --format '{{.State | json}}' 容器名
docker inspect --format '{{.NetworkSettings | json}}' 容器名

2. if 判断输出状态

docker inspect --format '{{if .State.Running}}✅运行中{{else}}❌已停止{{end}}' 容器名

3. 批量查看所有容器状态

docker ps -a --format '{{.Names}}' | xargs -I {} sh -c "echo ===== {} =====; docker inspect --format '状态:{{.State.Status}} 退出码:{{.State.ExitCode}}' {}"
