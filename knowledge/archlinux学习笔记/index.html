Archlinux学习笔记

← 返回知识库

Linux / 系统#知识库#Linux / 系统#Arch#Linux

记录我从接触、安装到日常使用 Arch Linux 过程中的核心知识点、常见问题与心得。
适合有一定 Linux 基础、想进一步理解系统原理并拥抱 DIY 哲学的读者。

一、为什么选择 Arch Linux

  • 滚动更新 ：没有大版本升级的概念，软件始终接近上游最新版。
  • KISS 原则 ：Keep It Simple, Stupid。简洁指的是系统设计简洁，不隐藏复杂性，让用户理解和掌控系统。
  • 以用户为中心 ：不给“开箱即用”的默认全家桶，你需要自己搭
  • 一切——桌面、网络、音频、服务等。
  • 优秀的 Wiki ：Arch Wiki 几乎是整个 Linux 社区最重要的文档资源之一，很多非 Arch 用户也会查阅。
  • AUR（Arch User Repository） ：海量由社区维护的软件包构建脚本，几乎什么软件都能找到。

二、安装过程核心要点

Arch 的安装是理解系统的第一课。关键步骤如下（以 UEFI + GPT 为例）：

1. 引导与网络

# 验证启动模式
ls /sys/firmware/efi/efivars   # 有输出则为 UEFI

# 连接网络
iwctl                           # 进入交互式 wifi 连接工具
# 或 ip link, dhcpcd 等
ping archlinux.org              # 检查连通性

2. 磁盘分区与挂载

lsblk -f                        # 查看磁盘
cgdisk /dev/nvme0n1             # 或使用 fdisk、parted

# 典型分区方案（UEFI）
# /dev/nvme0n1p1  EFI System Partition (512MiB, type ef00)
# /dev/nvme0n1p2  Root Partition       (剩余空间, type 8300 Linux filesystem)

mkfs.fat -F32 /dev/nvme0n1p1
mkfs.ext4 /dev/nvme0n1p2

mount /dev/nvme0n1p2 /mnt
mount --mkdir /dev/nvme0n1p1 /mnt/boot

3. 安装基本系统

# 建议先编辑镜像列表，把国内镜像（如清华 tuna）放在最前面
vim /etc/pacman.d/mirrorlist

pacstrap -K /mnt base base-devel linux linux-firmware vim sudo networkmanager

4. 生成 fstab 并 Chroot

genfstab -U /mnt >> /mnt/etc/fstab
arch-chroot /mnt

5. 基本系统配置（在 chroot 环境中）

# 时区与时区同步
ln -sf /usr/share/zoneinfo/Asia/Shanghai /etc/localtime
hwclock --systohc

# 本地化
vim /etc/locale.gen           # 取消 en_US.UTF-8 UTF-8 以及中文等
locale-gen
echo "LANG=en_US.UTF-8" > /etc/locale.conf

# 网络设置
echo "myhostname" > /etc/hostname
systemctl enable NetworkManager

# Root 密码与普通用户
passwd
useradd -m -G wheel myuser
passwd myuser

# 赋予 wheel 组 sudo 权限
EDITOR=vim visudo            # 取消 %wheel ALL=(ALL:ALL) ALL 注释

6. 引导加载程序（GRUB 示例）

pacman -S grub efibootmgr
grub-install --target=x86_64-efi --efi-directory=/boot --bootloader-id=GRUB
grub-mkconfig -o /boot/grub/grub.cfg

安装完成后退出、卸载并重启：

exit
umount -R /mnt
reboot

学习笔记提示 ：安装过程中每一次命令的输入都是理解系统组件的好机会。遇到问题先查阅 Arch Wiki Installation guide 。

三、Pacman 包管理速查

Pacman 是 Arch 的二进制包管器，常用操作如下：

# 全面系统更新
sudo pacman -Syu

# 搜索软件
pacman -Ss keyword

# 安装软件
sudo pacman -S package_name

# 删除软件（保留依赖）
sudo pacman -R package_name

# 删除软件及不再被需要的依赖
sudo pacman -Rns package_name

# 列出显式安装的包
pacman -Qe

# 列出孤立包（不再被依赖的包）
pacman -Qdt

# 清理缓存（保留最近3个版本）
sudo paccache -r
# 或手动：sudo pacman -Sc

提高 Pacman 体验的技巧 ：
编辑 /etc/pacman.conf ，开启以下选项：

  • Color ：彩色输出
  • ParallelDownloads = 5 ：并行下载
  • 在 [multilib] 处取消注释，以便安装 32 位库（如需要 Steam）
  • 可以加 ILoveCandy 让进度条变成吃豆人（娱乐项）

四、AUR 与构建系统

  • AUR 是用户维护的构建脚本仓库，不是二进制包源。
  • 每个 AUR 包都对应一个 PKGBUILD 文件，用来描述如何下载源码、编译并打包。
  • 使用方式：下载 PKGBUILD → 手动检查内容 → 运行 makepkg -si 编译安装。

安装 AUR 助手（简化流程，但依然需要审查） ：
主流助手有 paru 和 yay ，这里以 paru 为例：

sudo pacman -S --needed git base-devel
git clone https://aur.archlinux.org/paru.git
cd paru
makepkg -si

使用 AUR 助手示例 ：

paru -S google-chrome

助手会自动处理 AUR 依赖和更新。

⚠️ 安全守则：永远在安装前检查 PKGBUILD 和 .install 文件，尤其是新包或更新频繁的包。

五、图形化界面与常用软件

Arch 本身是纯命令行的，需要手动安装图形环境：

# 安装 Xorg 或 Wayland
sudo pacman -S xorg plasma-meta sddm   # KDE Plasma
# 或 gnome gdm

# 启动显示管理器
sudo systemctl enable sddm

常用基础软件组合：

sudo pacman -S firefox alacritty nautilus noto-fonts-cjk power-profiles-daemon
paru -S visual-studio-code-bin

六、系统维护与好习惯

1. 定期更新与备份

  • 建议每周至少更新一次，避免跨度太大导致依赖问题。
  • 更新前可以看一眼 Arch Linux 官网新闻 ，若有重大干预会提前说明。
  • 使用 timeshift 做系统快照，搭配 rsync 或 btrfs 快照非常安心。

2. 处理 .pacnew 文件

更新后若出现 .pacnew 文件，说明配置文件有新版。使用 pacdiff 对比合并：

sudo pacdiff

3. 清理孤儿包与缓存

# 移除不被依赖的包
sudo pacman -Qdtq | sudo pacman -Rs -

# 清理 systemd 日志大小
sudo journalctl --vacuum-size=200M

4. 镜像源管理

使用 reflector 自动生成最快的镜像列表：

sudo pacman -S reflector
sudo reflector --country China --age 12 --protocol https --sort rate --save /etc/pacman.d/mirrorlist

七、常见故障排错速记

问题 可能原因与解决
更新时提示数据库锁/var/lib/pacman/db.lck 有未完成的 pacman 进程，确认后删除锁文件 sudo rm /var/lib/pacman/db.lck
开机卡在 grub 救援模式 使用 Live 盘 chroot 重新安装/配置 grub
找不到无线网卡 lspci -k 检查驱动，安装 linux-firmware 或专有固件（如 iwlwifi）
Nvidia 驱动黑屏 参考 Wiki，添加内核参数 nvidia_drm.modeset=1，安装 nvidia 包并生成 initramfs
无法挂载 NTFS 分区 安装 ntfs-3g 并正确挂载

核心思路：出现问题 → 观察日志 (journalctl -xe) → 搜索 Arch Wiki → 社区论坛/BBS。

  • 必读经典 ：

九、写在最后

接触 Arch Linux 最大的收获不是系统本身，而是 学会如何学习 。
安装过程要求你文件系统、引导、网络、用户权限等概念清晰；日常维护让你养成阅读文档、关注上游变更的习惯。一旦你“驯服”了 Arch，其他任何发行版都只是界面的切换。

这篇笔记会持续更新，随着使用的深入补充内核调优、容器化、安全加固等内容。如果你也在学习 Arch，欢迎一起交流。

保持好奇，追求简洁，始终掌控你自己的系统。
