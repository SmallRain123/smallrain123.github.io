VTD安装教程

注意：VTD (Virtual Test Drive) 是德国 VIRES 公司（现隶属于 Hexagon）开发的商业仿真软件，主要用于自动驾驶和 ADAS 系统的开发测试。您需要拥有合法的软件授权（License）和安装包才能完成安装。本教程基于通用的 Linux 安装流程和公开资料整理，具体步骤可能因 VTD 版本不同而有所差异。

简介

VTD (Virtual Test Drive) 是一款高保真度的自动驾驶场景仿真软件，支持：

  • 道路网络建模 (OpenDRIVE)
  • 交通场景生成 (OpenSCENARIO)
  • 传感器仿真（摄像头、雷达、激光雷达等）
  • 实时高精度渲染
  • 支持 SIL/HIL/VIL 等多种测试模式

VTD 原生运行于 Linux 平台，推荐使用 Ubuntu LTS 版本。

系统要求

硬件要求（推荐）

组件 最低要求 推荐配置
CPU 4 核 8 核以上 (Intel i7/i9 或 AMD Ryzen 7/9)
内存 16 GB 32 GB 或更高
显卡 NVIDIA GTX 1060 / Quadro P2000 NVIDIA RTX 3080 / Quadro RTX 5000 或更高
存储 50 GB 可用空间 100 GB SSD 或更高
显示器 1920x1080 多屏支持（分布式仿真）

软件要求

  • 操作系统: Ubuntu 20.04 LTS 或 22.04 LTS（推荐 20.04，兼容性更好）
  • 显卡驱动: NVIDIA 专有驱动 (版本 470+ 或根据 VTD 版本要求)
  • OpenGL: 4.5 或更高
  • 网络: 千兆以太网（用于分布式仿真）

安装前准备

3.1 更新系统

sudo apt update
sudo apt upgrade -y
sudo reboot

3.2 安装 NVIDIA 显卡驱动

VTD 高度依赖 GPU 进行实时渲染，必须安装正确的 NVIDIA 专有驱动。

方法一：使用 ubuntu-drivers（推荐）

# 查看推荐的驱动版本
ubuntu-drivers devices

# 自动安装推荐驱动
sudo ubuntu-drivers autoinstall

# 或者手动指定版本（例如 nvidia-driver-525）
sudo apt install -y nvidia-driver-525

方法二：使用官方.run 文件安装

  1. 从 NVIDIA 官网 下载对应驱动的 .run 文件

  2. 禁用 Nouveau 开源驱动：

    sudo bash -c "echo blacklist nouveau > /etc/modprobe.d/blacklist-nouveau.conf"
sudo bash -c "echo options nouveau modeset=0 >> /etc/modprobe.d/blacklist-nouveau.conf"
sudo update-initramfs -u
sudo reboot

  3. 进入文本模式（Ctrl+Alt+F3），登录并停止显示管理器：

    sudo systemctl stop gdm3  # 或 lightdm/sddm

  4. 安装驱动：

    chmod +x NVIDIA-Linux-x86_64-xxx.xx.run
sudo ./NVIDIA-Linux-x86_64-xxx.xx.run --no-opengl-files

  5. 重启系统：

    sudo reboot

验证驱动安装

nvidia-smi
glxinfo | grep "OpenGL version"

确保能看到显卡信息和 OpenGL 版本 ≥ 4.5。

VTD 安装步骤

前提：您已从 VIRES/Hexagon 官方获取 VTD 安装包（通常为 .tar.gz 或 .iso 格式）和 License 文件。

步骤 1：解压安装包

假设安装包位于 /home/user/Downloads/VTD_202X_Linux.tar.gz：

cd /home/user/Downloads
tar -xzvf VTD_202X_Linux.tar.gz
cd VTD_202X_Linux

步骤 2：运行安装脚本

VTD 通常提供交互式安装脚本：

sudo ./install.sh

或使用图形化安装器（如果提供）：

./setup.sh

按照提示完成以下操作：

  1. 接受许可协议
  2. 选择安装路径（默认 /opt/VTD 或 /usr/local/VTD）
  3. 选择要安装的组件（Road Designer, Simulation Server, Viewer 等）
  4. 输入 License 服务器地址或本地 License 文件路径

步骤 3：复制 License 文件

将您的 License 文件（通常是 license.dat 或 vtd.lic）复制到指定目录：

sudo cp /path/to/your/license.dat /opt/VTD/license/

或在安装过程中指定路径。

环境变量配置

VTD 依赖多个环境变量来定位资源和库文件。

临时设置（当前终端会话）

export VTD_ROOT=/opt/VTD
export VTD_VERSION=202X
export LD_LIBRARY_PATH=$VTD_ROOT/lib:$LD_LIBRARY_PATH
export PATH=$VTD_ROOT/bin:$PATH
export VTD_LICENSE_FILE=/opt/VTD/license/license.dat

永久设置（推荐）

编辑 ~/.bashrc 或 ~/.profile：

nano ~/.bashrc

在文件末尾添加：

# VTD Environment Variables
export VTD_ROOT=/opt/VTD
export VTD_VERSION=202X
export LD_LIBRARY_PATH=$VTD_ROOT/lib:$LD_LIBRARY_PATH
export PATH=$VTD_ROOT/bin:$PATH
export VTD_LICENSE_FILE=$VTD_ROOT/license/license.dat

使配置生效：

source ~/.bashrc

验证环境变量

echo $VTD_ROOT
echo $VTD_LICENSE_FILE
ls $VTD_ROOT/bin

启动与基本使用

启动 VTD 组件

VTD 包含多个可执行组件，常用命令如下：

1. 启动 Road Designer (ROD) - 道路编辑器

$VTD_ROOT/bin/RoadDesigner
# 或直接
RoadDesigner

2. 启动 Simulation Server

$VTD_ROOT/bin/SimulationServer

3. 启动 Viewer (视景渲染器)

$VTD_ROOT/bin/Viewer

4. 使用快捷启动脚本（如果提供）

某些版本提供一键启动脚本：

$VTD_ROOT/bin/start_vtd.sh

加载示例场景

  1. 打开 Road Designer
  2. 加载示例道路文件（通常位于 $VTD_ROOT/data/roads/）
  3. 保存并导出为 OpenDRIVE (.xodr) 格式
  4. 在 Simulation Server 中加载场景配置文件 (.cfg)
  5. 启动仿真

基本操作流程

1. 使用 Road Designer 创建/编辑道路网络
2. 使用 Scenario Editor 配置交通场景 (OpenSCENARIO)
3. 配置传感器模型（摄像头、雷达等）
4. 启动 Simulation Server
5. 启动 Viewer 查看实时渲染
6. 连接被测算法（通过 API 或 UDP/TCP）
7. 运行仿真并记录数据

常见问题与解决

问题 1: 启动时提示 “License not found” 或 “License checkout failed”

解决方案：

  • 检查 VTD_LICENSE_FILE 环境变量是否正确指向 License 文件

  • 确认 License 文件未过期且与当前 VTD 版本匹配

  • 如果使用网络 License，确保 License 服务器可达：

    ping <license_server_ip>
telnet <license_server_ip> <port>

问题 2: Viewer 启动后黑屏或崩溃

解决方案：

  • 确认 NVIDIA 驱动已正确安装：nvidia-smi
  • 检查 OpenGL 版本：glxinfo | grep "OpenGL version"
  • 尝试降低渲染设置（在 Viewer 配置文件中）
  • 确保没有其他程序占用 GPU 资源

问题 3: 无法找到共享库 (libXXX.so)

解决方案：

  • 确认 LD_LIBRARY_PATH 包含 VTD 的 lib 目录
  • 运行 ldd $VTD_ROOT/bin/Viewer 检查缺失的库
  • 安装缺失的系统依赖包

问题 4: 分布式仿真无法连接

解决方案：

  • 配置 NFS 共享目录（用于共享场景文件）

  • 配置 SSH 免密登录

  • 检查防火墙设置：

    sudo ufw allow from <client_ip> to any port 22
sudo ufw allow from <client_ip> to any port <vtd_port>

  • 确保所有机器时间同步（使用 NTP）

问题 5: Ubuntu 升级后 VTD 无法启动

解决方案：

  • 内核升级可能导致 NVIDIA 驱动失效，重新安装驱动
  • 检查 VTD 与新 Ubuntu 版本的兼容性（可能需要升级 VTD）
  • 回退到之前工作的内核版本（通过 GRUB）
